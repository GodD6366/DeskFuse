# DeskFuse 官网设计锚：Apple 式产品叙事

当前方向：**Apple 式产品官网**（2026-11-07，用户明确要求替换此前的“桌面杂志”）。
这是官网唯一设计锚；页面改动先对照这里，不在单个组件里临时发明新风格。

## 1. 页面与功能契约

- 产品：DeskFuse，桌面多机协作工具。不同电脑共用键鼠、剪贴板与文件，并按设备能力提供远程应用和麦克风等功能，局域网直连。
- 受众：同时使用 2–3 台 Mac 的开发者、设计师和重度用户。
- 3 秒内必须看懂：产品名、“一套键鼠，连接每台电脑”、下载入口。
- 品牌主张只讲电脑与设备，不绑定当前操作系统；具体平台只出现在下载选项、系统要求和功能边界中。
- 必须能完成：查看五项核心能力、确认真的产品界面、比较替代方案、选择芯片下载、复制 Homebrew 命令、找到 FAQ 与反馈入口。
- 情绪：克制、可信、精致。让真实产品截图成为主角，不让装饰抢占注意力。

## 2. 视觉语言

### 色彩

| 角色 | 值 | 用法 |
|---|---|---|
| 白 | `#ffffff` | 首屏与主要章节 |
| 浅灰 | `#f5f5f7` | 相邻章节、产品舞台 |
| 墨黑 | `#1d1d1f` | 标题与主要文字 |
| 正文灰 | `#4e4e52` | 正文 |
| 次级灰 | `#6e6e73` | 版本、图注与辅助信息 |
| 规则线 | `#d2d2d7` | 仅用于表格、FAQ 和页脚 |
| Apple 蓝 | `#0071e3` | 主按钮、焦点和互动状态 |
| 链接蓝 | `#0066cc` | 浅色背景文字链接 |

- 全页保持浅色主题，以白色与浅灰切换章节；不用暗色插入页。
- 蓝色只表达可操作，不给普通图标或装饰随意上色。
- 无渐变、光晕、纹理、紫蓝色、朱砂色和装饰性发光。

### 字体

- 中文与西文统一使用系统栈：`-apple-system / BlinkMacSystemFont / SF Pro / PingFang SC / Microsoft YaHei`。
- 标题字重 600，中文 `letter-spacing: 0`；正文 400，强调 500/600；不使用 700 和斜体。
- Hero 产品名桌面 96px，章节标题 40–64px，面板标题 28–36px。
- 中文正文 16–17px、行高 1.6–1.75；导语 20–26px、行高约 1.6。
- 不加载装饰性中文 webfont；不再使用宋体标题或等宽编号眉批。

### 布局与组件

- 内容宽 `min(1120px, 100% - 48px)`，移动端左右 16px。
- 每屏只讲一个重点；章节间距 88–144px，靠空间和背景色分场，不靠卡片海。
- Hero 使用居中的产品名、短承诺、双操作与大幅真实产品组合图。
- 导航高 48px，白色半透明 + 轻微背景模糊，与首屏共享同一空间。
- 主按钮为蓝色胶囊；次操作为蓝色文字链接或蓝色描边胶囊。
- 能力选择是一组胶囊 tab；面板保持文字与产品图/功能示意左右结构。
- 截图使用克制的窗口或设备框，不伪装成实时状态，不显示虚构延迟或在线数据。
- 卡片圆角最多 12px；手机等物理设备框可按设备外形使用更大圆角。
- 阴影只用于产品窗口/设备，柔和且单层；普通内容区不浮起。

### 动效

- 强度 6/10，以短促透明度、位移和按压反馈为主；能力面板切换 180ms。
- 不滚动劫持、不自动轮播、不漂浮装饰、不使用 `transition: all`。
- 所有动效尊重 `prefers-reduced-motion`；核心内容和操作不依赖动画。

## 3. 首页结构

1. 融合式导航：品牌、能力、对比、下载、帮助、GitHub。
2. Hero：DeskFuse、跨设备核心承诺、下载入口、真实剪贴板与屏幕排布产品组合。
3. 五项能力：键鼠共享 → 剪贴板 → 麦克风 → 鼠标按键 → 远程应用；tab 支持键盘与 URL 状态。
4. 本地与隐私：设备密钥、局域网直连、无需账号。
5. 手机传输：真实手机页面与“不用装 App”的操作路径。
6. 功能对比：桌面表格、移动端分行布局，保留来源链接。
7. 下载：版本、当前桌面安装包、Homebrew、三步安装和 Beta 说明。
8. FAQ 与问题反馈。
9. 结尾下载和简洁页脚。

## 4. Apple DNA 转译（不是品牌复刻）

1. **产品先行**：大幅真实截图占据首屏视觉中心，界面退后。
2. **白 / 浅灰章节节奏**：不用报纸规则线切分内容。
3. **单一蓝色操作色**：下载、链接、tab 与焦点共享同一交互语言。
4. **紧凑标题 + 大量留白**：标题字重 600，正文保持舒展中文行高。
5. **胶囊操作与融合导航**：操作清晰，导航不遮挡产品叙事。

记忆点：不同电脑的真实产品界面在同一舞台前后相接，首屏直接表达“一套键鼠，连接每台电脑”。

## 5. Do / Don't

Do：
- 使用真实截图和真实发布信息；示意图必须明确只是功能关系，不冒充产品界面。
- 每屏保留一个主焦点；下载按钮在全页统一写“下载 DeskFuse”。
- 1440 / 1024 / 768 / 640 / 390 / 320 均无页面横向溢出。
- tab、FAQ、移动导航、下载和复制均支持键盘并有可见焦点。

Don't：
- 不要宋体、杂志期号、Fig. 图号、朱砂、报纸分栏和编号眉批。
- 不要渐变字、光晕、暗色大面板、无意义 Bento、三等分卡片海。
- 不要负字距、斜体、700 中文标题和加载/成功状态常驻文案。
- 不要假在线状态、假延迟、假产品数据。

## 6. 验收

- `npm run typecheck`、`npm run build`、`git diff --check` 通过。
- 桌面与移动端真实浏览器截图；首屏、五项能力、手机、对比、下载和 FAQ 均检查。
- 最新版本回退、两种芯片下载、Homebrew 复制、能力键盘切换、移动导航和 FAQ 可用。
- 页面无横向溢出；中文正文 ≥16px，无斜体、无负字距；减少动态效果设置有效。

## 7. 局域网传输页（同一套 Apple 式浅色语言）

- 2026-11-07 用户明确要求局域网页面与官网一起改掉旧的桌面杂志风格。
- 源码：`crates/deskfuse-engine/src/lan_web_assets/`，由 Mac 应用局域网服务直接提供；不改变 API、CSP、传输与复制回退逻辑。
- 与官网共享白 `#ffffff`、浅灰 `#f5f5f7`、墨黑 `#1d1d1f`、正文灰 `#4e4e52`、操作蓝 `#0071e3`；连接在线可保留功能性的绿色，错误使用明确的红色。
- 标题与操作都用系统中文字体；标题 600、正文 400/500/600，中文零字距、无斜体；输入框 16px，避免 iOS 聚焦缩放。
- 「传输 / 查看」使用浅灰分段控件；文字输入、照片上传、列表与预览使用有任务语义的白色表面和 12px 圆角，不做营销页式大留白。
- 图标统一为 1.6px 圆头线稿；复制图标继续使用 DOM 内联 SVG，不依赖 data URI，符合页面 CSP。
- 保留连接状态、上传进度、失败重试、空态、筛选、列表/瀑布流、预览弹层和安全区适配；所有触控目标至少 44px。
- 官网手机区的 `mobile.webp` 必须从这一页重新截取，不能保留旧的桌面杂志页面截图。
