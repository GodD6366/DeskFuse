# DeskFuse 官网设计锚：桌面杂志

选定方向：**B · 桌面杂志**（2026-11-04，用户从四方向预览中选择 B）。
这是官网唯一的设计锚；后续页面改动先对照这里，不在单个组件里临时发明新风格。

## 1. 页面是什么

- 产品：DeskFuse，macOS 多机协作工具。几台 Mac 共用键鼠、剪贴板、文件、远程应用和麦克风，局域网直连。
- 受众：同时使用 2–3 台 Mac 的开发者、设计师和重度用户。
- 功能契约：3 秒内看懂“几台电脑当一台用”；能确认它是真实产品、本地直连、有真实截图；能下载对应芯片的安装包；能找到对比、常见问题和反馈入口。
- 情绪：像翻开一本关于桌面的独立设计杂志——有作者、有版面、有图版说明，不像通用 SaaS 官网。

## 2. 视觉语言

### 颜色

| 角色 | 值 | 用法 |
|---|---|---|
| 纸 | `#faf8f2` | 页面底色 |
| 浅纸 | `#f2ede2` | 插入页、侧栏底色，不超过版面 20% |
| 墨 | `#1b1a17` | 标题、正文、规则线 |
| 次级墨 | `#514b41` | 长正文、说明 |
| 灰墨 | `#6f685d` | 图注、元信息 |
| 规则线 | `#d7cfbf` | 细分隔线 |
| 强规则线 | `#1b1a17` | 章节顶线、图版边框 |
| 朱砂 | `#b23a2a` | 链接、页码、图注编号、主按钮；全页只用一个重音色 |

- 不使用渐变、光晕、毛玻璃、紫色、荧光绿。
- 朱砂是编辑标记，不是装饰色；不要给每个图标、每个标签都上色。
- 暗色只用于个别“插入页”（例如对比表的表头），不把整段做成深色面板。

### 字体

- 中文标题：`"Songti SC", "STSong", "SimSun", "Noto Serif CJK SC", serif`，字重 500/600。
- 中文正文/UI：系统无衬线栈（PingFang SC / Microsoft YaHei / Noto Sans SC），字重 400/500/600。
- 西文与数字：`"Iowan Old Style", "Palatino Linotype", "Times New Roman", serif` 用于刊头/页码；`ui-monospace` 用于编号、尺寸、版本号。
- **全部中文标题 `letter-spacing: 0`，禁止负字距。** 中文标题不用 700，避免苹方伪粗发虚。
- 正文 17px，行高 1.75；正文最多 36em。图注 13px，行高 1.6。
- 不使用斜体；强调靠字重、字号、朱砂色和缩进。

### 版面

- 页面宽 `min(1240px, 100% - 64px)`；桌面 12 栏，栏距 24px。
- 每个章节以一条 1px 墨线开始；标题从页面左边距起排，导语在右栏。
- 不在章节标题上方放 `SECTION 02` 这类编号眉批；期号、图号和页码只出现在报头、图注与页脚。
- 章节标题左对齐，标题与导语分成不等比两栏；不要居中 Hero + 三等分卡片。
- 图片是“图版”：1px 墨色边框、4–6px 内边距（像印刷留白）、图注编号 `Fig. 01`，图注说明“这是什么、来自哪里”。
- 按钮是硬边矩形（2px 圆角）；链接是朱砂下划线。没有胶囊、没有悬浮圆角卡片、没有投影堆叠。
- 允许不填满：留白是版面的一部分；但每个空白旁边要有页码、规则线或图注，不能是无意义的空。

### 组件

- 导航：报头式。左侧图标 + `DeskFuse`（衬线），中间带两位编号的栏目链接，右侧 GitHub 与下载链接。底部 1px 墨线；不使用玻璃拟态。
- 主按钮：朱砂底、白字、48px 高、2px 圆角。
- 次按钮：透明底、1px 墨线、墨字；或朱砂下划线文本。
- 标签：小型等宽/大写文字，前面 5px 朱砂方点；不使用圆角胶囊。
- 表格：只有横线和竖线，表头用小型等宽标签；DeskFuse 列用极浅纸色底 + 朱砂页码，不用整列高亮。
- FAQ：`details` 行，1px 规则线，`+ / −` 用细线字符，不用圆形按钮。
- 页脚：版权页/版权栏，4 栏，顶部 1px 墨线。

### 动效

- 强度 3/10：只做颜色、下划线、图版进入（透明度 + 6px 位移，240ms）和 FAQ 展开。
- 不使用滚动劫持、漂浮卡片、无限跑马灯、光晕呼吸。
- 所有动效必须有 `prefers-reduced-motion` 降级。

## 3. 页面结构

1. 报头导航（sticky，纸色，1px 底线）
2. 首屏：期号条 + 左侧宋体大标题/导语/CTA + 右侧真实剪贴板图版 + 底部四栏“本期内容”
3. 下载：版本信息 + 芯片下载 + 安装步骤 + Homebrew/全部版本，用规则线分栏
4. 能力：左侧目录按开发顺序（键鼠共享、剪贴板、麦克风、鼠标按键、远程应用），右侧专题文章 + 编号要点 + 边注；保留 tab 可访问性
5. 能力索引：分类筛选（文字下划线）+ 两栏编号索引，不用卡片
6. 核心优势：一张真实屏幕排布图版 + 右侧 pull quote 与三条观察；远程应用默认开启虚拟屏幕
7. 对比：报纸式对比表；移动端按行展开，不用卡片
8. 手机：纸面照片随笔，真实手机页面图版 + 图注
9. 帮助：FAQ 规则线列表 + 右侧“联系编辑”框
10. 结尾：宋体大标题 + 下载 + 版权页
11. 页脚

## 4. Do / Don't

Do：

- 先读真实内容，再决定版面；标题、图注、页码要像编辑写出来的。
- 真实截图必须占一个明确的图版位置，带图注和来源。
- 中文标题零字距；正文 17px、行高 1.75。
- 章节之间用 1px 墨线和页码建立节奏，而不是靠背景色块。

Don't：

- 不要负字距、不要 650/700 中文标题、不要斜体。
- 不要圆角卡片海、胶囊标签海、居中 Hero + 三等分卡片、渐变字、光晕、玻璃拟态。
- 不要把朱砂用作每个图标的颜色。
- 不要用假的界面图、假的 3 台设备状态、假的延迟读数。
- 不要让移动端出现横向溢出的表格或图版。

## 5. 验收

- 1440 / 1024 / 768 / 640 / 390 / 320 无横向页面溢出。
- 中文标题 `letter-spacing` 为 0；无斜体；正文 ≥17px；图注 ≥13px。
- 主按钮与朱砂文字对比度 ≥4.5:1；正文墨色 ≥7:1。
- 首屏、图版、下载入口、能力切换、筛选、FAQ、下载/复制交互全部可用。
- 真实截图：剪贴板（首屏）、屏幕排布（优势区）、手机页面（手机区）。
- `npm run typecheck`、`npm run build`、`git diff --check` 通过。


## 6. DNA（编辑杂志传统）

没有复制某个品牌站的脸；从独立杂志与报纸版面借了 5 个具体值：

1. **1px 墨线切章节**：每条线都是版面的开始，不用阴影或背景色块分隔。
2. **宋体大标题 + 系统无衬线正文**：标题 500 字重、零字距；正文 17px / 1.75。
3. **图版语法**：真实截图放进 1px 墨框，6px 内边距，配 `Fig. 01` 编号和来源说明。
4. **朱砂只做编辑标记**：链接、页码、要点编号、主按钮；不拿它涂每个图标。
5. **报头/页脚/期号**：`ISSUE 01`、`DESKFUSE / 001` 建立出版物感；章节标题本身不编号。

记忆点：一张像杂志跨页的桌面工具首页——宋体大标题、真实图版、朱砂页码，而不是圆角卡片堆出来的 SaaS 页。功能顺序按开发顺序：键鼠共享 → 剪贴板 → 麦克风 → 鼠标按键 → 远程应用；远程应用默认虚拟屏幕。


## 7. 局域网传输页（随身页）

- 源码：`crates/deskfuse-engine/src/lan_web_assets/`，由 Mac 应用局域网服务直接提供。
- 与官网同一套颜色：纸 `#faf8f2`、墨 `#1b1a17`、朱砂 `#b23a2a`、规则线 `#d7cfbf`；不再用蓝色控件。
- 页面标题用系统宋体；操作正文用系统无衬线；输入框 16px，避免 iOS 聚焦缩放。
- 图标统一为 1.6px 方头线稿：品牌图标、搜索、列表/瀑布流、上传加号、关闭、复制；复制图标是 DOM 内联 SVG，不依赖 data URI，符合页面 CSP。
- 布局：报头 + 双栏文字标签页；传输页是表单/规则线；查看页是列表/瀑布流；预览是方角纸面弹层。
- 不引入新依赖；动效仅颜色与按压，`prefers-reduced-motion` 关闭。
- 官网手机区的 `mobile.webp` 必须从这一页重新截取，不能保留旧蓝色页面截图。
