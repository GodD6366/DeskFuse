# 安装窗口

参考 Qoder 的单页安装流程，使用 DeskFuse 品牌图标、现有蓝色强调色和原生窗口。
这些图片来自实际 SwiftUI / AppKit 视图渲染。布局按 600 × 585 pt 设计，
整体以 2/3 比例呈现为 400 × 390 pt，文字、图标、间距和按钮一起缩放；
原生标题栏按钮保留系统尺寸。图片不含系统窗口阴影。

- `welcome.png`：点击安装。
- `installing.png`：复制与签名验证期间的等待状态。
- `installed.png`：安装完成，点击打开应用。
- `welcome-en.png`：英文欢迎页。
- `failed.png`：错误常驻，可重试。

重新渲染：`./scripts/preview-installer.sh`。
安装事务检查：`./scripts/test-app-installation.sh`。检查只操作临时目录和临时 DMG，
不替换本机应用，不启动共享引擎；正式证书签名、公证与真实权限流程另行验证。

安装副本通过签名校验后，清理其继承的下载隔离属性，避免安装完成后被
App Translocation 再次转移到临时目录并进入安装页。原下载包的隔离属性保留。
回归检查覆盖带隔离标记的应用及嵌套可执行文件、其他属性保留和安装后签名。
