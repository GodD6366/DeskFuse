# uniDesk 当前界面与行为约定

2026-09-14 用户确认本地页面设计稿已过时并删除。后续以当前实际 UI、用户截图和已确认的问题修正为依据；本文保留有效行为契约，不作为另一套视觉设计稿。

## 当前结构

- 主窗口为单实例原生 `Window`，在统一灰底上排列导航和白色内容卡片。功能侧栏包含剪贴板、键鼠共享、设备、传输，使用细线小图标（约 15 pt，未选中为黑色/`.primary`，不要用大号满色或系统强调色符号）。设置入口位于侧栏底部本机状态卡的齿轮。
- 剪贴板为功能侧栏、历史列表、内容预览三栏；侧栏理想宽 196 pt，历史栏初始宽 280 pt、可在 240–360 pt 内拖动调整，预览吸收剩余空间。所有分栏铺满可用高度，不能依赖列表内容的最小尺寸。
- 页面标题、副文和暂存入口位于三栏正文顶部；历史列表含搜索、分组和来源筛选、真实历史及底部同步开关。初次进入选中首条可见历史；只读取预览，不自动恢复系统剪贴板。筛选为空时呈现真实空态。
- 预览含标题、来源、大小、文件可用性、图片/文件/文本内容及底部格式信息。图片保持比例，提供适合窗口或填满预览；文本和文件列表底部留出滚动空间，不被操作条遮挡。
- 设置使用单实例原生 `Settings` 场景，默认 960 × 720 pt，最小内容 860 × 580 pt；侧栏齿轮、⌘,、应用菜单和菜单栏面板统一路由到同一窗口，不改变主窗口页面及剪贴板选择。七个分类改为纵向细线图标与文字导航，字形对齐设置原图；正文不重复显示横向分类栏，设置行标签靠左、操作靠右。主窗口与设置窗口保留系统红绿灯及原生标题栏拖动区域。
- 通用设置按共享、系统、诊断三组呈现，隐藏公网连接入口，不改写已经保存的网络设置。系统组提供“隐藏 Dock 图标”（仅本地 macOS 偏好，不同步到其他设备；隐藏后仅保留菜单栏图标，主窗口与设置仍从菜单栏进入）。其余分类沿用既有功能与保存语义；窄 AppKit `NSTabViewController` 桥接保留各页编辑状态、按需加载并隔离隐藏页焦点。设置容器只比较设置相关引擎投影，设备心跳与历史刷新不重建分页。
- 主窗口使用内缩圆角稳定内容面，右侧始终只有这一块圆角主体；搜索、刷新、共享设置、暂存区等功能按钮放在各自页面内部，不占用窗口工具栏。导航直接位于窗口灰底上，无独立底板或竖向分界；白色主体四周留出灰底，通过轻微阴影形成悬浮层级。2026-09-14 按用户截图修正：白色主体顶边与底边保持相同 12 pt 外边距，正文卡延伸进透明标题栏区域，导航仍保留系统安全区避开红绿灯与标题栏拖动区。复制、暂存和更多操作移至预览下方，图片、文字和文件正文不被操作条覆盖；图片显示方式位于下方元数据行。⌘F 通过当前主窗口命令聚焦历史或设备搜索，不在设置窗口触发后台首页搜索。
- 正常窗口 1200 × 780 pt，最小 960 × 620 pt；侧栏可折叠，正文可滚动。
- 设备列表底部同时提供手动 IPv4 配对，保留自动发现和接收方确认。设备详情展示完整连接候选列表（地址、发现来源、健康状态），并区分当前活动地址与下次优先候选；离线时不把第一条候选当作当前连接。优先路径是类型偏好而不是 IP 绑定，候选不等于已连通，不根据 IP 前缀猜测雷电/Wi-Fi 类型。
- 键鼠页围绕真实显示器布局和实际可用性展开；开关、权限和已就绪分别展示。
- 方形暂存区保持独立、不夺焦点的 240 × 240 pt 面板，展开 480 × 420 pt；发送改为单级设备菜单，选择一台设备即发送整批，不再展开工作流二级菜单。

- 图片按需后台读取并限制缩略图长边为 320 px；文字、文件与文件夹使用真实预览及元数据。文件历史的 `length` 是引用数量，不显示为文件字节大小。
- 打开默认选中第一条可见记录；⌘F 聚焦搜索。无历史或无匹配时显示真实空态并禁用复制，无匹配时可清除筛选。单击或方向键只选择；双击、回车和当前面板内的 ⌘1–9 恢复原始内容并粘贴回打开前的应用，数字始终对应当前结果前九条。仅复制不发送粘贴事件。粘贴准备返回引擎实际写入版本后才返回目标应用，校验目标、会话、修饰键与剪贴板版本；失败保留错误，旧会话回调不能关闭重新打开的面板。Esc/点外关闭，输入法组字期间不抢快捷键。
- 查看全部进入主窗口剪贴板并转交搜索、分组、来源和选择；完整内容搜索仍由 Rust 处理。
- 复制时间由 Rust 在实际记录事件时捕获并持久化。旧记录无时间时不生成“刚刚”或虚构分钟数；恢复/启动读取不是新复制事件。数据库增加 nullable 时间列，保留原始剪贴板快照编码与历史。
- 暂存区保留快捷入口；更多菜单保留运行状态、打开主窗口、收回键鼠、设置和退出。头尾复用原生材质与现有可访问性回退，正文使用稳定底面。

## 剪贴板列表迭代（2026-09-13）

- 搜索下方显示固定“全部”、自定义智能/手动列表和固定新增入口；标签横向滚动，保留现有系统材质和稳定内容底面。
- 2026-09-14 按用户截图要求移除主窗口独立的“全部 / 文字 / 图片 / 文件”筛选行。类型筛选统一使用智能分组；“＋”提供文字、图片、文件建组模板，保存后选中该分组，可继续编辑条件、排序或删除。主窗口与菜单栏共用此入口，不额外保存隐藏类型筛选状态。
- 默认创建“图片”“文件”智能分组，初始排列在“全部”之后；已有库升级时也补齐这两个默认分组。使用固定分组与初始化操作标识跨设备去重，编辑、排序及删除沿用普通分组逻辑；重启或同步不会重建已删除分组或重置已编辑配置。文字分组按需从“＋”创建。
- 主窗口与菜单栏共用 Rust/SQLite 列表；查询先应用分组规则/搜索/设备再分页，来源设备按稳定 ID 区分。历史行按用户确认的布局：左列是来源 App 图标（由记录保存的 bundle ID 解析，不用本机前台 App 冒充，解析不到时回退内容类型图标），主区域是内容本身（图片显示真实预览，文字/文件显示短标题），右列只显示 `HH:mm`；不再展示设备、容量、类型和完整日期。纯文本按内容归并，同一段文字复用同一行，本地捕获与同步接收不再各留一条。
- 历史行支持右键“删除”和键盘 Delete/Backspace 删除；删除同时移除同一记录的手动列表镜像，归档删除写入同步墓碑，不被后续合并复活。菜单栏面板的条目右键同样提供删除。
- 2026-09-14 增加列表 / 瀑布流两种展示方式，主窗口切换入口在来源筛选行右侧，菜单栏面板在标题行；两者用同一个 `unidesk.clipboard.displayMode` 偏好，任一处切换另一处跟随。瀑布流为两列自然高度卡片，按预计高度分列；特别长的纯文本卡片跨两列占一整行，前后内容继续按两列排布；方向键上下沿当前列移动、左右进入相邻列中垂直位置最近的卡片，跨整行卡片作为上下段落边界；单卡片内容最大高度 236 pt，超长文字截断、超高图片等比缩放，不让单个 block 撑长整列。卡片头显示来源 App 图标、App 名称和 `HH:mm`。
- 主窗口列表的图片预览在内容区居中显示，不再贴着来源图标居左。菜单栏行与瀑布流卡片的缩略图复用同一 (记录 ID, 像素) 缓存，图片未就绪时保留固定尺寸占位，打开面板不再闪烁或跳动。
- 2026-09-14 增加每条记录的可编辑标题：默认空，瀑布流卡片只显示真实标题（没有标题时该行留空），主窗口列表行在没有自定义标题时回退到内容短标题；双击标题或右键“编辑标题”就地编辑，回车或失焦保存，写入 `cl_items.title`（`set_item_title` 操作，上限 200 字），清空即删除自定义标题。瀑布流卡片的来源 App 图标做成右下角背景水印：向左倾斜 45°、贴角，约 3/4 可见，其余裁掉，透明度 0.05；菜单栏面板编辑标题时键盘交给输入框。标题同时参与自由搜索与智能列表“文本”条件。

## 键鼠布局补充基准（2026-09-11）

键鼠共享页的屏幕布局使用点阵画布、简单描边矩形、极浅填充，不画壁纸、设备机身、底座或支架。显示器尺寸与坐标使用引擎真实布局，不写死演示屏幕。矩形内部必须显示顺序编号、设备名称、宽 × 高尺寸；尺寸使用引擎逻辑桌面数据并标注 pt，不冒充物理英寸。画布外图例同步编号、设备名、尺寸、就绪状态，悬停可查看设备信息；按设备身份分配不同颜色，同一设备的屏幕保持相同配色；本机以文字标识，未就绪使用虚线及文字区分，不以固定橙红色作通用边框。同一设备多屏仍整体拖动。

### 排布管理（2026-09-13）

- 主控页以“当前屏幕排布”为核心，画布占据正文宽度；移除右侧只读可用性检查器。编号按稳定设备/显示器 ID 排序生成，仅为当前布局标识，不冒充系统显示器编号。
- 画布上方提供“添加设备屏幕”，从已配对的设备网络成员中选择；按整台设备添加全部真实屏幕，不生成占位显示器。尚未收到拓扑的参与设备保留在画布下方列表，显示等待状态、实际阻碍和设备页检查入口。
- 下方按设备分组展示屏幕编号与尺寸、设备可用性以及“移除”；画布中的远端屏幕右键菜单也可移除整台设备。本机屏幕不能移除。
- 添加/移除直接更新引擎参与设备列表，不解除配对、不删除已保存位置、不隐式开启总共享开关；移除后不再向该设备共享键鼠。重新添加仍须满足真实链路与授权条件。
- 高级共享设置不再重复编辑参与设备。紧急收回与快捷键保留为底部紧凑操作栏。窄窗口内容垂直排列并允许滚动。

## 主控布局与被控状态（2026-09-12）

- 屏幕画布、设备颜色、拖动布局和共享设置只在主控电脑显示。被控电脑只显示被控状态及“停止被控”按钮；未连接时展示等待状态，停止后展示已停止状态。不向被控端同步可编辑布局。
- 主控界面和鼠标穿越使用同一 Rust 布局解析器。拖动时提供边缘磁吸预览，松手时贴合最近的不重叠共边，避免缝隙、重叠或仅角点接触导致不能穿越。同一设备的原生多屏相对位置不变，保存时保留所有可见设备的位置，离线设备位置不丢失。
- 调整布局只更新路由几何，不关闭原生输入可用性，不重新启动权限适配器或创建主控激活意图。涉及正在控制的屏幕时仍释放当前输入并安全收回，不能保留旧坐标继续注入。
- 本轮仅按默认流程完成构建、签名和包检查，真实两机往返穿越、停止被控、断线重连及窗口视觉验收仍需单独记录。

## 原生 Liquid Glass

- 窗口统一灰底、正文稳定实色；导航操作和系统菜单沿用原生材质与可访问性回退。
- 预览下方操作按钮、图片显示方式菜单使用系统 `glassEffect(.regular.interactive())`，共同位于一个 `GlassEffectContainer`；主要复制操作使用原生蓝色强调玻璃，禁用状态使用中性外观，不覆盖正文。
- 侧栏本机状态和文件暂存面板沿用原生玻璃浮层；历史同步开关位于白底列表页脚。玻璃透色由系统、壁纸、窗口激活和可访问性设置决定，不硬编码图中的蓝绿光晕。
- macOS 26+ 使用原生 Liquid Glass。macOS 14/15 使用系统材质，开启降低透明度时浮层使用系统实色底面。
- 不使用 CSS、透明渐变、重复模糊层或屏幕截图来模拟系统玻璃。正文、文本和图片预览保留稳定内容区域。

构建必须同时保留最低 macOS 14.0 和真实的 macOS 26+ linked SDK。仅写 `glassEffect`，但最终 Mach-O 错标旧 SDK，不构成原生玻璃交付；构建和 DMG 校验脚本均检查 SDK 标记。Debug 的 Window 菜单提供 1200 × 780 和 960 × 620 pt 两个真实窗口尺寸，便于复现视觉检查；Release 不包含这些菜单。

## 剪贴板滚动、内存与日志（2026-09-15）

- 主窗口保留原生 `List` 按需行渲染；主窗口及菜单栏瀑布流使用惰性列。分页触发器位于惰性内容内部，到达末尾自动按 50 条读取下一页；只有失败时提供重试，不再常驻“加载更多”按钮。筛选重置分页代次，过时请求不能覆盖当前查询。
- 图片行和卡片在缩略图到达前后保持相同图片槽位高度，避免加载造成滚动位置跳变。离屏释放行内图片；退出主页面清空分页及预览投影，关闭菜单栏面板时释放预览并只保留最近一页轻量查询元数据，使再次唤起可立即呈现旧结果并在后台刷新。
- 缩略图直接由 Rust 按显示尺寸生成，不先跨 FFI 读取 1600 px 详情图再缩小；读取与解码串行，离屏取消排队，缓存同时限制为 96 个条目、16 MiB 估算解码成本，并在内存压力下清空。上述预算不是应用整体 RSS 上限。
- Rust 历史热缓存只保留最多 50 条、32 MiB 内容预算，原始历史仍以 SQLite 为准；单条当前剪贴板超预算时保留该条以保持原生操作完整。启动逐条读取，避免同时加载 50 份大图及原生表示；状态快照内的图片预览降为 160 px。
- 日志每次启动默认开启，磁盘位置为 `~/Library/Logs/uniDesk/diagnostics-{UTC epoch hour}.jsonl`，每个 UTC 小时一个切片。启动和运行期间每分钟清理一次超过 7 天的切片；为避免保留超龄记录，按切片起始小时到期整片删除。崩溃记录同样按 7 天清理；退出应用期间在下次启动补清理。
- 日志仅包含已有诊断元数据，单字段最多 1024 字节；使用 256 条有界后台队列，磁盘 I/O 不在界面或输入热路径执行，队列溢出记录丢弃计数。开关仍仅影响本次运行，关闭后保留错误记录及已写入文件。

## 2026-09-16 状态栏面板开合与首次点击

用户反馈：状态栏图标第一次点击只闪一下、第二次才打开面板；面板内切换列表/瀑布流的第一次点击也常被吞掉。修正只调整交互，不改变面板内容、尺寸与视觉。

- 状态栏图标按下即开合，与系统菜单栏条目一致：不再依赖鼠标抬起时才发送的按钮动作，激活应用的那一次点击也就不会中断按钮跟踪、导致第一次点击落空。
- 剪贴板弹窗自行管理关闭，不再使用 AppKit 的 transient 行为：该行为会在状态栏图标自己的按下事件里抢先关闭面板，使开合不可控。点应用外、点本应用其它窗口、Esc 和切换应用（⌘-Tab 等失焦）仍会收起；粘贴交接期间面板由粘贴流程自己关闭，不打断会话。
- 状态栏弹窗显示时应用取得键盘焦点（该面板本就接管搜索框、⌘F、方向键、Delete 与 Esc），因此面板出现后的第一次点击即作用到控件；全局快捷键唤起的鼠标旁面板仍是原生非激活面板，不夺焦点。
- 状态栏弹窗若处于“已记录为显示但窗口已不可见”的残留状态，下一次点击会先复位再打开，避免把一次点击浪费在关闭一个看不见的面板。
- 本轮按隔离 AppKit 探针核对按下即开合、开合交替与失焦收起，并按默认流程做构建、签名、包与 NAS 完整性检查；真实状态栏点击、面板内点击和视觉验收仍需在安装包上执行。
