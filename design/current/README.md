# DeskFuse 当前界面与行为约定

2026-09-14 用户确认本地页面设计稿已过时并删除。后续以当前实际 UI、用户截图和已确认的问题修正为依据；本文保留有效行为契约，不作为另一套视觉设计稿。

## 系统设置风格界面（2026-10-12）

用户要求把界面换成 macOS「系统设置」的视觉风格，并附系统设置截图作为参照；已确认三点：范围＝主窗口 + 设置窗口，深度＝只换视觉外壳（页面内功能布局、交互、状态全部保留），侧栏＝彩色方块图标。

- 新增 `apps/deskfuse-macos/Sources/DeskFuse/SystemSettingsStyle.swift` 作为唯一风格来源：`SystemSettingsMetrics`（行高 30 / 行圆角 7 / 图标方块 21 圆角 6 / block 圆角 10）与共享组件 `SystemSettingsIcon`、`SystemSettingsSidebarRow`、`systemSettingsSidebarBackground()`、`systemSettingsContentBackground()`、`systemSettingsBlock()`、`SystemSettingsBlockDivider`、`SystemSettingsSectionLabel`、`SystemSettingsPageHeader`、`SystemSettingsFormBlock`、`SystemSettingsFormPage`。
- 侧栏改为系统设置同款：21 pt 彩色圆角方块内嵌白色符号，选中项整行 `accentColor` 实心圆角高亮、文字变白，图标方块保留自身识别色（`Page.color` / `SettingsCategory.color`）。仍嵌在原生 `List(selection:)` 里，配合 `NativeListSelection` 关掉系统高亮，键盘方向键、VoiceOver 语义与选中滚动定位不变。
- **推翻 2026-09-14 的旧约定**：「侧栏使用细线小图标（约 15 pt，未选中黑色、不要用大号满色或系统强调色符号）」与「主窗口右侧始终只有一块白色圆角主体、四周留 12 pt 灰底、以阴影形成悬浮层级」。现在内容区直接铺满，没有外层卡片、没有 12 pt 留白、没有阴影；`WorkspaceContentSurface` 与 `SidebarNavRow` 已删除。
- 底色分层：窗口底 `windowBackgroundColor`；侧栏 `.regularMaterial`（减弱透明度时回退实心）；内容区 `textBackgroundColor`；block 用 `Color.primary.opacity`（浅色 0.05 / 深色 0.075，减弱透明度时 0.07 / 0.11）。用相对叠色而不是 `windowBackgroundColor`/`controlBackgroundColor`，因为后两者会随深浅模式互换明暗关系，无法稳定表达「比背景深一档的分组」。
- 设置窗口同样去掉白色外壳。原本用原生 `.formStyle(.grouped)` 的六个分类页（权限、剪贴板、键鼠共享、快捷键、传输与存储、更新）与工作流编辑页全部改写为 `SystemSettingsFormPage` + `SystemSettingsFormBlock`：macOS 原生分组表单呈现的是「灰底 + 白卡」，与本设计的「亮底 + 灰卡」明暗相反，且卡片填充没有公开 API 可改；改写时行内容（Toggle / Picker / TextField / LabeledContent / Stepper）原样保留。
- 剪贴板页内部侧栏（分组列表）与它控制的历史列表同属内容区，沿用同一个亮底、靠分栏线分隔；只有最外层主侧栏用材质灰底。该栏选中态改为蓝色实心圆角；侧栏底部的工作流入口从实心蓝卡改为灰底 block。
- 键鼠页的流畅度卡片与屏幕排布分组各自只保留**一层** `systemSettingsBlock()`（圆角 10、无描边），取代 2026-10-12 早先记录的 16 pt 圆角 `.regularMaterial` + `.separator` 描边版本。屏幕排布画布不再单独铺 `.regularMaterial` 或描边，点阵直接画在外层分组底上：画布自身再铺一层材质会和外层分组叠成两层灰底。画布只保留一层圆角裁剪，用于限制拖动溢出并与外层分组圆角对齐。
- 已知取舍：工作流编辑页的步骤拖动排序依赖 `List` 语义，改写后移除，改由每行已有的上移/下移按钮排序。`NativeGlassCardSurface` 因零调用点删除；浮层与空态（`FeatureGateView`、错误提示、`RemoteApplicationView`）继续保留玻璃材质，不改成灰块。
- 验证范围：开发版实机截取了主窗口五个页面、设置窗口八个分类、剪贴板工作流分段，以及浅色与深色两种外观。未覆盖：提高对比度与减弱透明度辅助功能设置、窗口尺寸极限、两机功能验收。

## 菜单栏面板底色与选中态（2026-10-13）

用户反馈菜单栏剪贴板面板「整体偏暗、已选中状态不清晰」。两个现象同一个根因：面板底色全是半透明材质。

- 面板窗口是 `isOpaque = false` + `backgroundColor = .clear`，`.glassEffect(.regular)` / `.regularMaterial` 直接透出壁纸和后面的窗口，桌面偏暗时整个面板跟着发闷，浅色选中填充也被压掉。`ClipboardPopupSurface` 现在在玻璃**之下**垫一层 60% 的 `windowBackgroundColor`：只压透色，材质质感保留，底色深浅仍由系统语义色决定，不硬编码具体颜色；「减弱透明度」分支仍是实心底，行为不变。
- 选中填充从 `accent.opacity(0.08)` 提到 `0.18`，描边从 1.5 pt 提到 2 pt（`DeskFuseBrand.selectionFill` / `selectionStrokeWidth`）。这两个 token 由瀑布流卡片、主窗口历史行、菜单栏列表行、设备行、剪贴板分组行和远程应用选择器共用，改动全局一致。
- 键鼠页屏幕排布移除设备屏幕矩形上的鼠标悬停提示（原 `DisplayLayout.screenHelp` 及其 `.help`），状态信息由矩形内已有的常驻标签承载；随之为零调用点的 `screenHelp` 一并删除。
- 验证范围：开发版实机截取菜单栏面板（瀑布流 + 选中卡片）与主窗口剪贴板页，浅色外观。未覆盖深色外观下的面板垫底效果与提高对比度设置。

## 本机文案与链接卡片（2026-10-13）

同一台机器在界面上有四种叫法：「本机 · DeskFuse」（引擎本机设备名）、「本机」（相对远端的标识）、「这台 Mac」（来源显示）、「DeskFuse」（应用名）。用户要求统一。

- 引擎 `local_device()` 与 `AppModel::offline` 的本机设备名从「本机 · DeskFuse」改为「这台 Mac」，设备页、键鼠画布本机屏幕、侧栏状态提示与工作流规则设备名随之统一。**「本机」作为相对概念保留**（设备页分组标题、画布上的「本机 / 远端」、屏幕标签的「屏幕 01 · 本机」），它表达的是「相对于远端设备」，不是设备名。
- 卡片来源文案原来直接取 `library.devices` 的原始名，绕过了 `displaySource` 的本机规范化，因此漏出引擎内部的「本机 · DeskFuse」，而同一个条目的预览头部和元数据行显示的是「这台 Mac」。新增 `ClipboardLibraryStore.displayDeviceNames(_:)` 让设备 ID → 展示名走同一套规范化，主窗口（`ClipboardView`）与菜单栏面板（两处 `MenuBarClipboardView`）改用它。工作流规则里本机名的兜底值也从「本机」改为「这台 Mac」。
- 瀑布流链接卡片不再用「域名首字母 + 蓝色圆形徽标」，改为链接图标（`link`，次要色）；`linkParts` 随之不再需要 `initial` 字段。主窗口与菜单栏共用这一处实现。
- 验证范围：开发版实机截取主窗口剪贴板页（瀑布流卡片来源、预览头部、元数据行三处一致）与设备页（本机条目显示「这台 Mac」）。

## 当前结构

- 主窗口为单实例原生 `Window`，在统一灰底上排列导航和内容区。功能侧栏包含剪贴板、键鼠共享、设备、传输，图标与选中态见上一节「系统设置风格界面」。设置入口位于侧栏底部本机状态卡：点击「这台 Mac」或齿轮都打开设置。齿轮左侧是检查更新图标，调用与设置页相同的检查命令；手动安装包、正在检查、已就绪或正在安装时禁用。检测到可安装更新时，本机卡上方显示快速更新按钮。
- 剪贴板为功能侧栏、历史列表、内容预览三栏；侧栏理想宽 196 pt，历史栏默认取当前可用的最大宽度（上限 360 pt），可在 240–360 pt 内拖动调整，至少为预览保留 340 pt。所有分栏铺满可用高度，不能依赖列表内容的最小尺寸。
- 页面标题、副文和暂存入口位于三栏正文顶部；历史列表含搜索、分组和来源筛选、真实历史及底部同步开关。初次进入选中首条可见历史；只读取预览，不自动恢复系统剪贴板。筛选为空时呈现真实空态。
- 预览含标题、来源、大小、文件可用性、图片/文件/文本内容及底部格式信息。图片保持比例，提供适合窗口或填满预览；文本和文件列表底部留出滚动空间，不被操作条遮挡。
- 设置使用单实例原生 `Settings` 场景，默认 960 × 720 pt，最小内容 860 × 580 pt；侧栏齿轮、⌘,、应用菜单和菜单栏面板统一路由到同一窗口，不改变主窗口页面及剪贴板选择。八个分类使用彩色方块图标与文字导航（见上一节「系统设置风格界面」）；正文不重复显示横向分类栏，设置行标签靠左、操作靠右。主窗口与设置窗口保留系统红绿灯及原生标题栏拖动区域。
- 通用设置按共享、系统、诊断三组呈现，隐藏公网连接入口，不改写已经保存的网络设置。系统组提供“隐藏 Dock 图标”（仅本地 macOS 偏好，不同步到其他设备；隐藏后仅保留菜单栏图标，主窗口与设置仍从菜单栏进入）。其余分类沿用既有功能与保存语义；窄 AppKit `NSTabViewController` 桥接保留各页编辑状态、按需加载并隔离隐藏页焦点。设置容器只比较设置相关引擎投影，设备心跳与历史刷新不重建分页。
- 主窗口内容区直接铺满侧栏右侧，没有外层卡片、内缩留白或阴影（见上一节）。搜索、刷新、共享设置、暂存区等功能按钮放在各自页面内部，不占用窗口工具栏。页面内分组统一用浅灰圆角 block 承载；正文卡延伸进透明标题栏区域，导航仍保留系统安全区避开红绿灯与标题栏拖动区。复制、暂存和更多操作移至预览下方，图片、文字和文件正文不被操作条覆盖；图片显示方式位于下方元数据行。⌘F 通过当前主窗口命令聚焦历史或设备搜索，不在设置窗口触发后台首页搜索。
- 正常窗口 1200 × 780 pt，最小 960 × 620 pt；侧栏可折叠，正文可滚动。
- 设备标题行提供“+”二级入口，展开手动 IPv4 配对；保留自动发现和接收方确认。已配对/附近/已阻止各组内在线（控制通道已连接）的设备排在前面。设备详情展示完整连接候选列表（地址、发现来源、健康状态），并区分当前活动地址与下次优先候选；离线时不把第一条候选当作当前连接。优先路径是类型偏好而不是 IP 绑定，候选不等于已连通，不根据 IP 前缀猜测雷电/Wi-Fi 类型。点「断开连接」后保持断开，发现、唤醒和刷新都不会自动连回，直到再点「重新连接」。
- 「退出设备网络」是本机配置里的红色按钮，出现在选中本机时的详情中，不出现在其他设备详情里。
- 键鼠页围绕真实显示器布局和实际可用性展开；开关、权限和已就绪分别展示。「作为主控」和「共享键鼠」默认关闭，启用主控不会自动打开共享。添加设备屏幕、共享设置、共享键鼠与「快捷键设置」同一行；不再提供依赖鼠标点击的「紧急收回」按钮。

- 方形暂存区保持独立、不夺焦点的 240 × 240 pt 面板，展开 480 × 420 pt；发送改为单级设备菜单，选择一台设备即发送整批，不再展开工作流二级菜单。

## 菜单栏最近剪贴板（2026-09-12）

菜单栏继续沿用当前实际 UI 及以下行为，不替代独立文件暂存区。

- 菜单栏使用 NSStatusItem 和原生弹出面板，目标 440 × 780 pt，小屏按当前显示器可用区域收缩；来源设备保留在标题行，保留搜索与列表标签；按 2026-09-14 用户截图要求移除顶部空白标题栏及类型筛选/总数整行。鼠标旁面板无标题栏，⌘F 与条目 ⌘1–9 提示仅在按住 Command 时显示，松开、失焦或关闭后隐藏；提示显隐不改变条目尺寸。底部固定为查看全部、工作流、共享到设备同一行；移除显式粘贴按钮和常驻快捷键提示，仅复制保留在更多菜单和条目右键菜单。点击状态栏图标仍锚定状态栏；全局快捷键使用鼠标所在屏幕的原生面板，优先鼠标右侧、空间不足时左侧，并限制在可用屏幕内。两种入口共用同一 SwiftUI 内容与粘贴会话，同一时刻只显示一个。
- 图片按需后台读取并限制缩略图长边为 320 px；文字、文件与文件夹使用真实预览及元数据。文件历史的 `length` 是引用数量，不显示为文件字节大小。
- 打开默认选中第一条可见记录；⌘F 聚焦搜索。无历史或无匹配时显示真实空态并禁用复制，无匹配时可清除筛选。单击或方向键只选择；双击、回车和当前面板内的 ⌘1–9 恢复原始内容并粘贴回打开前的应用，数字始终对应当前结果前九条。仅复制不发送粘贴事件。粘贴准备返回引擎实际写入版本后才返回目标应用，校验目标、会话、修饰键与剪贴板版本；失败保留错误，旧会话回调不能关闭重新打开的面板。Esc/点外关闭，输入法组字期间不抢快捷键。
- 查看全部进入主窗口剪贴板并转交搜索、分组、来源和选择；完整内容搜索仍由 Rust 处理。
- 复制时间由 Rust 在实际记录事件时捕获并持久化。旧记录无时间时不生成“刚刚”或虚构分钟数；恢复/启动读取不是新复制事件。数据库增加 nullable 时间列，保留原始剪贴板快照编码与历史。
- 暂存区保留快捷入口；更多菜单保留运行状态、打开主窗口、收回键鼠、设置和退出。头尾复用原生材质与现有可访问性回退，正文使用稳定底面。
- 交付证据见 `artifacts/validation/2026-09-12-menubar-clipboard/`。按默认流程仅构建、签名、DMG 与 NAS 完整性检查，尚不构成实际菜单栏视觉/键盘操作、Finder 或两机验收。

## 剪贴板列表迭代（2026-09-13）

- 搜索下方显示固定“全部”、自定义智能/手动列表和固定新增入口；标签横向滚动，保留现有系统材质和稳定内容底面。
- 2026-09-14 按用户截图要求移除主窗口独立的“全部 / 文字 / 图片 / 文件”筛选行。类型筛选统一使用智能分组；“＋”提供文字、图片、文件建组模板，保存后选中该分组，可继续编辑条件、排序或删除。主窗口与菜单栏共用此入口，不额外保存隐藏类型筛选状态。
- 默认创建“图片”“文件”智能分组，初始排列在“全部”之后；已有库升级时也补齐这两个默认分组。使用固定分组与初始化操作标识跨设备去重，编辑、排序及删除沿用普通分组逻辑；重启或同步不会重建已删除分组或重置已编辑配置。文字分组按需从“＋”创建。
- 主窗口与菜单栏共用 Rust/SQLite 列表；查询先应用分组规则/搜索/设备再分页，来源设备按稳定 ID 区分。历史行按用户确认的布局：左列是来源 App 图标（由记录保存的 bundle ID 解析，不用本机前台 App 冒充，解析不到时回退内容类型图标），主区域是内容本身（图片显示真实预览，文字/文件显示短标题），右列只显示 `HH:mm`；不再展示设备、容量、类型和完整日期。纯文本按内容归并，同一段文字复用同一行，本地捕获与同步接收不再各留一条。远端写回使用 CurrentHostOnly 与隐藏 origin marker；系统接力带有 `com.apple.is-remote-clipboard` 时直接跳过入库和广播，系统剥掉该标记或接力先到时再由 10 秒等价指纹账本（文本 NFC/换行、图片 dHash）认回声。
- 历史行支持右键“删除”和键盘 Delete/Backspace 删除；删除同时移除同一记录的手动列表镜像，归档删除写入同步墓碑，不被后续合并复活。菜单栏面板的条目右键同样提供删除。

## 剪贴板滚动、内存与日志（2026-09-15）

- 主窗口保留原生 `List` 按需行渲染；主窗口及菜单栏瀑布流使用惰性列。分页触发器位于惰性内容内部，到达末尾自动按 50 条读取下一页；只有失败时提供重试，不再常驻“加载更多”按钮。筛选重置分页代次，过时请求不能覆盖当前查询。
- 图片行和卡片在缩略图到达前后保持相同图片槽位高度，避免加载造成滚动位置跳变。离屏释放行内图片；退出主页面清空分页及预览投影，关闭菜单栏面板时释放预览并只保留最近一页轻量查询元数据，使再次唤起可立即呈现旧结果并在后台刷新。
- 缩略图直接由 Rust 按显示尺寸生成，不先跨 FFI 读取 1600 px 详情图再缩小；读取与解码串行，离屏取消排队，缓存同时限制为 96 个条目、16 MiB 估算解码成本，并在内存压力下清空。上述预算不是应用整体 RSS 上限。
- Rust 历史热缓存只保留最多 50 条、32 MiB 内容预算，原始历史仍以 SQLite 为准；单条当前剪贴板超预算时保留该条以保持原生操作完整。启动逐条读取，避免同时加载 50 份大图及原生表示；状态快照内的图片预览降为 160 px。
- 日志每次启动默认开启，磁盘位置为 `~/Library/Logs/DeskFuse/diagnostics-{UTC epoch hour}.jsonl`，每个 UTC 小时一个切片。启动和运行期间每分钟清理一次超过 7 天的切片；为避免保留超龄记录，按切片起始小时到期整片删除。崩溃记录同样按 7 天清理；退出应用期间在下次启动补清理。

- 状态栏弹窗若处于“已记录为显示但窗口已不可见”的残留状态，下一次点击会先复位再打开，避免把一次点击浪费在关闭一个看不见的面板。
- 本轮按隔离 AppKit 探针核对按下即开合、开合交替与失焦收起，并按默认流程做构建、签名、包与 NAS 完整性检查；真实状态栏点击、面板内点击和视觉验收仍需在安装包上执行。

## 2026-09-20 启动授权弹窗

- 每次打开软件（`applicationDidFinishLaunching`，自检流程除外）检测三项权限：辅助功能、完全磁盘访问、屏幕录制；任一缺失且未勾选“不再提醒”时，在主窗口弹出一次授权弹窗。屏幕录制仅远程应用功能需要，弹窗文案已注明；输入监听不展示、不探测、不申请。
- 授权交互使用 [PermissionFlow](https://github.com/jaywcjlove/PermissionFlow)：每行「前往授权」按钮打开对应系统设置隐私页并伴随拖拽授权浮板；状态读取走 PermissionFlow 官方 API（`AXIsProcessTrusted`、文件探测、`CGPreflightScreenCaptureAccess`），不触发系统弹窗。仅链接屏幕录制状态扩展，包依赖固定于 `Package.resolved`。
- 弹窗内「不再提醒」按权限粒度记录到本地偏好；被勾选的缺失权限不再触发启动弹窗，之后若该权限被授予则自动解除抑制（用户再撤销时恢复提醒）。设置「权限」页脚在存在抑制项时提供「恢复启动授权提醒」。本次运行内仅弹一次，授权补齐后弹窗自动收起。
- 授权弹窗显示期间不拦截应用退出。系统设置授权后弹出的「退出并重新打开」必须能结束本进程，并由系统重新打开 DeskFuse。
