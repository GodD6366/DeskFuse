# 图片工作流

uniDesk 图片流程由有序步骤组成，保存于 Rust 引擎的 SQLite 设置中。Swift 负责编辑与状态展示，不另存业务配置。

## 使用入口

- 设置中的图片流程：新建、添加示例、命名、复制、启停、删除、排列步骤及设置全局快捷键。
- 剪贴板历史预览与菜单栏：对选中的图片运行流程；历史入口只复制结果，不向当前 uniDesk 窗口自动粘贴。
- 全局快捷键：读取当前剪贴板，处理完成后执行最后的复制或粘贴步骤。
- 系统快捷指令中的「运行 uniDesk 图片流程」：可传入单个图片文件，未传入时读取剪贴板。默认返回图片文件，不修改剪贴板；显式开启「执行流程末尾输出」才执行复制或粘贴。

## 步骤与输出

支持压缩、调整尺寸、转换格式、调用系统快捷指令及末尾复制/粘贴。每个流程必须且只能有一个输出步骤，并置于末尾。最多保存 100 个流程，每个最多 32 步。

- 压缩支持质量或目标体积。目标体积是最终输出上限，不是中间步骤的大小保证；多个上限取最小值。最终按质量搜索及必要的缩小尺寸尝试满足上限，无法满足时明确失败，不输出超限结果。
- 转换支持 PNG、JPEG、WebP、HEIC。JPEG/HEIC 不保留透明度时使用白色底面。PNG 无有损质量参数。
- 调整尺寸支持最长边或百分比。
- 图片及单个图片文件可作为输入；不支持多文件、目录或多帧图片。输入上限 128 MiB，像素解码另有保护上限。
- 默认跟随来源：剪贴板图片输出图片，图片文件输出新文件；也可以显式选择图片或文件。用户源文件不覆盖，输出命名为 `<原名>-processed.<格式>`。
- 图片剪贴板同时包含最终编码与由最终结果生成的 TIFF 兼容表示。接收应用可能选择不同表示，最终编码字节数不代表接收应用保存后的文件大小。

## 系统快捷指令调用边界

流程可以通过稳定标识选择系统快捷指令，将当前图片作为文件输入，并要求返回单张有效图片文件。外部步骤最长等待 10 分钟，可以取消；取消会终止等待的命令进程，但不能撤销系统快捷指令已经执行的外部副作用。

本版支持两个方向独立调用，**不支持嵌套回调**：uniDesk 正在等待系统快捷指令时，任何新的 uniDesk 图片流程调用都会被拒绝，避免循环调用或误认调用来源。未实现原提案的多层嵌套链。

## 执行保护

普通新任务会取消前一个运行任务。输出前检查取消状态、原剪贴板版本、源文件变化及自动粘贴目标焦点；过时结果不得覆盖较新的剪贴板。全局快捷键需要 macOS 原生辅助功能权限，与快捷键录制状态协调。自动粘贴等待物理修饰键释放；提交结果后粘贴失败时保留已复制结果，可手动粘贴。

处理文件位于 uniDesk 自有缓存中，执行期间通过缓存租约保护；已发布文件不能因后续粘贴失败而删除。没有写入用户源文件或更改配对、身份、系统权限。

## 验收边界

构建、App Intents 元数据生成、签名及 DMG 完整性检查不等于功能验收。需要用户在真实应用中确认全局快捷键、原生粘贴、系统快捷指令发现与执行、取消以及目标应用格式接收行为。
