# 源码与发行仓库

`GodD6366/DeskFuse` 是公开源码仓库，同时承载 GitHub Release 安装包、Homebrew tap（根目录 `Casks/`）、官网与更新镜像站点（`web/`，由 Pages 发布到 `deskfuse.godd.cc`）和问题反馈。自有代码适用根目录 LICENSE；历史已经公开的版本保留当时授予的许可，第三方许可正文与来源保持不变。

原发行仓库 `GodD6366/deskfuse-release` 只保留 v0.7.0 及更早的安装包。过渡版本同时发布到两个仓库后归档，见 [发行指南](RELEASING.md#发行仓库合并过渡)。

本地缓存、密钥、签名材料、构建产物和用户数据仍不得提交。具体开发与分发规则见 [架构](ARCHITECTURE.md) 和 [发行指南](RELEASING.md)。
