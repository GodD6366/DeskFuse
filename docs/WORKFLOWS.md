# 工作流

uniDesk 工作流由 Rust 引擎统一保存、运行和同步，Swift 只维护未保存的编辑草稿与状态投影。工作流支持文字、图片、多个文件及文件夹，不再限定单张图片。

## 入口与步骤

- 设置 → 工作流：新建、复制、命名、启停、步骤排序、输入类型及全局快捷键；共享规则和同步状态也在这里维护。
- 剪贴板历史预览、菜单栏：对选中的内容运行，或选择设备与工作流共享。历史本地运行只复制结果，不向 uniDesk 窗口粘贴。
- 全局快捷键：读取当前剪贴板，执行末尾复制/粘贴。快捷键冲突只影响本机注册，不阻止定义同步；冲突状态需处理后再使用快捷键。
- 系统快捷指令中的「运行 uniDesk 工作流」：输入文字或多个文件/文件夹，均省略时读取剪贴板；默认返回结果文件集合，不修改剪贴板。文字结果返回 UTF-8 `result.txt`。显式启用末尾输出才复制/粘贴。

步骤：

| 步骤 | 语义 |
| --- | --- |
| 文字替换 | 区分大小写的字面查找替换，不使用正则，查找内容不能为空 |
| 首尾清理 | 去除整段文字首尾空白，不改动中间内容 |
| 批量重命名 | 只改所选顶层项目的输出名称，支持查找替换和前后缀，文件保留扩展名；目录内部名称不变，重名递增编号 |
| ZIP 打包 | 将所选文件和目录打为一个 ZIP，保持层级，不包含解压功能 |
| 图片压缩、调整尺寸、格式转换 | 沿用 PNG/JPEG/WebP/HEIC、质量/最终目标体积、最长边/比例；批量只接受明确选择的图片文件，不自动递归处理目录 |
| 系统快捷指令 | 通过本机绑定执行，声明返回文字、图片、文件集合，或跟随输入类型；输入为私有工作副本 |
| 复制/粘贴 | 必须且只能有一个，位于末尾；共享调用覆盖为“返回结果给发送链路”，不触碰发送端剪贴板 |

每个工作流最多 32 步。类型不兼容在编辑器中提示并在 Rust 中验证，不静默忽略不适用的文件。图片编码输入上限 128 MiB，像素解码另有保护；普通文件和文件夹遵守现有缓存与传输容量政策，不套用图片容量限制。图片转换仍使用白色底面处理不支持透明度的格式，最终体积约束无法达到时失败而非输出超限结果。

## 共享行为

工作流由发送端 A 执行，B 接收结果，不再次运行。同一次共享只执行一个工作流：

1. 手动指定工作流优先；手动“不处理，直接共享”跳过自动规则。
2. 自动规则按发送设备、目标设备和内容类型匹配。指定目标优先于所有目标，同级按排序取第一条。
3. 不同目标设备独立选择流程，每个任务固定原始输入和定义版本，不将 B 的处理结果作为 C 的输入。

规则默认关闭，随定义同步，但只由规则指定的发送设备执行。普通剪贴板文件复制仍先发布引用，实际发送、对端请求粘贴或满足既有提前传输条件时才开始工作流文件处理。文件共享中的文字或原生图片结果物化为文件，沿用文件请求、校验和接收协议。

转换失败或本机依赖缺失时自动回退发送原内容，并显示失败原因与回退状态。主动取消、新复制替换旧内容、源文件变化/删除、连接失效不能借回退继续发送。已处理结果的传输重试复用结果，不重新执行系统快捷指令。

## 同步与更新

- 已配对的可信在线设备通过现有认证会话交换工作流摘要和版本记录，与剪贴板同步开关独立；首次连接、重连及修改后补齐差异。
- 定义与规则采用稳定 ID、逻辑修订、修改设备和删除标记。向量时钟区分因果更新与并发更新，并发按逻辑修订与设备 ID 决胜，竞争失败版本保留可恢复。删除标记防止离线设备复活旧定义。
- 只有对端确认的摘要与当前目录完全一致才显示同步完成；仅发送成功不算完成。
- 系统快捷指令本体不传输，原生 ID 留在本机绑定中；同步步骤使用逻辑标识。其他设备收到后需绑定自己的快捷指令，不按同名自动执行。
- 远端更新不覆盖未保存草稿；可以重新载入远端版本。运行中任务固定定义，后续编辑只影响新任务。
- 原本机 `image_workflows_v1` 一次性迁移到通用同步目录，保留 ID 与步骤；持久化成功后清除旧键，不双写。

## 输出与生命周期

所有文件操作使用 uniDesk 私有缓存副本，不覆盖用户源文件。读入前后及输出前核对源文件/目录清单。缓存租约保护源、执行中间产物和已发布结果；文件共享接管结果后继续由传输租约保护。符号链接和特殊文件不作为工作流输入。

本地输出仍检查原剪贴板版本、取消状态和粘贴目标焦点。普通本地新任务替换旧本地任务，共享任务按独立运行 ID 管理。外部快捷指令最长等待 10 分钟；取消终止等待的进程，不能撤销快捷指令已经产生的外部副作用。不支持系统快捷指令嵌套回调 uniDesk 工作流。

## 验收边界

默认交付仅构建、生成绑定/App Intents 元数据、签名、DMG 完整性和 NAS 校验，不运行功能测试。文字转换、文件夹/ZIP、快捷指令真实返回类型、失败回退、按需处理、取消、离线补齐和并发编辑需要真实应用与两机验收；不能以构建或包检查替代。
