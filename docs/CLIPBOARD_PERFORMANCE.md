# 剪贴板性能与验收

## 交互路径

本地粘贴只等待目标记录的原始快照读取、必要的文件解析、原生剪贴板写入及取消/覆盖校验。文件缓存保护使用已准备的文件路径，不回读整份原生剪贴板。使用时间使用持久单调时钟，通过独立维护线程合并排序，成功粘贴不等待数据库排序、索引发布、计数或清理。文件下载和目标应用焦点恢复属于必要操作，保持原有会话、取消、覆盖检查。

界面查询、计数、变更和媒体解码分别使用 Swift actor。数据库使用 WAL、三个只读连接和串行写连接；读取可选择空闲连接。查询携带 `query_id`，取消通过 SQLite progress handler 中断正在执行的 SQL，包括分组计数。

首屏默认 20 条，读取一条额外记录判断是否可翻页，不查询精确总数；总数独立异步补齐。游标使用使用时间/复制时间和记录 ID，保留旧 offset 协议兼容调用方。Swift 页面缓存最多 16 个首屏、滚动窗口最多 100 条，原始快照热缓存沿用 32 MiB 上限。

删除、重命名、分组变更和排序先应用界面投影，再等待持久回执。失败撤销对应操作；旧查询结果不会覆盖尚未反映到页面版本中的成功回执。UI 变更按提交顺序排队，分组排序和批量删除在一个合并事务中提交，失败不会留下部分变更。回执不附带统计和无关状态。历史删除的投影同时遮蔽旧热缓存；回执保留有界并触发权威页面刷新。移出当前手动分组立刻隐藏行。

删除和手动分组动作在同步回调中发布投影，随后才建立后台持久任务。已知记录元数据最多缓存 512 条；“全部”和手动分组计数同步应用有界增量，统计回执达到对应计数版本后停止叠加，失败撤回自身增量，连续加/移出不会重复计数。打开尚无首屏缓存的目标手动分组时，先呈现刚加入的记录；搜索或来源筛选保持查询结果约束。分页返回普通历史与冻结归档的关联 ID，删除归档会同步遮蔽旧的普通历史热缓存。创建归档与首次加入分组在同一个操作合并事务中提交，不重复删除/创建归档、回填正文或发送刷新事件。120 ms 防抖只针对输入变化，已有搜索的变更刷新不再额外等待。

变更通过 `ClipboardLibraryChanged` 事件推送，Swift 合并短时间内重复事件；仅写入同步日志而未改变列表投影的操作不触发 UI 刷新；打开视图时的 30 秒刷新用于兜底。计数延迟合并执行，单纯粘贴排序使用独立计数版本，不重新统计。准备超过 150 ms 才显示粘贴加载图标。

## 大数据存储

- `cl_item_metadata` 保存页面查询投影；原始多格式快照按内容哈希存于不可变 `cl_blobs`，新记录不把 BLOB 放入 `cl_items`。重命名、OCR 和排序更新不复制正文。
- 旧数据库按 ID 分批回填投影，完成前兼容查询保持可用。旧正文逐条迁到哈希表，缺失的哈希通过 64 KiB 读缓冲计算，不在 Rust 中另存一份；迁移事务可被交互写入中断并重试。
- 单字和双字搜索使用 `cl_short_terms`，通过 SQLite incremental blob 读取文档的 512 字节批次建立索引；未完成文档进入候选集并执行精确校验，迁移期间也不漏结果。较长搜索使用 trigram FTS 候选，最后以 Unicode 小写的字面子串校验，`%`、`_` 不作为通配符。
- 智能列表条件编译到 SQL，在分页前过滤；内容类型、应用和设备索引包含排序键。手动分组由成员索引生成候选，普通查询通过成员和活动列表连接，不拼接全部分组。
- 同步发布意图与新增/编辑内容在同一事务中提交，以持久单调版本防止旧后台回执误删新意图；重启可恢复。启动索引协调和身份迁移发布分批执行，不扩大旧普通历史的同步范围。作者版本时钟保存在小表，操作插入时增量更新。成员关系只保留最大因果操作的投影，首次访问旧关系回填后，继续增量维护；完整操作日志仍用于同步，不删除历史。
- 归档协调仅处理受本次操作影响的记录；重命名/排序分组不扫描其成员。文本和图片加入分组复用不可变正文，文件归档保留原文件注册逻辑。
- 到期记录在查询和恢复时逻辑隐藏。清空普通历史通过水位立即生效并保留手动归档；物理清理分批执行，孤立正文延后回收，保留新建正文的短时保护以覆盖未完成的归档操作。维护线程每轮最多 64 批、8 ms 执行片段（单批的大正文 I/O 另受 SQLite 取消检查约束），交互写入优先。

## 验证

正确性：`cargo test --locked -p deskfuse-engine clipboard_library`（18 项通过，2 个显式压测默认忽略），以及 Swift 的 `ClipboardPresentationTests`（3 项通过）。覆盖旧正文迁移、编辑后原始恢复、Unicode 短搜索及索引更新、逻辑到期、SQL 规则等价、计数取消、并发删除优先/因果重加和界面失败回滚。

规模探针（需要显式运行，不混入日常正确性测试）：

```sh
DESKFUSE_CLIPBOARD_BENCH_ROWS=10000 cargo test --locked -p deskfuse-engine clipboard_library::performance_regressions::scale_benchmark -- --ignored --nocapture
DESKFUSE_CLIPBOARD_BENCH_ROWS=100000 cargo test --locked -p deskfuse-engine clipboard_library::performance_regressions::scale_benchmark -- --ignored --nocapture
DESKFUSE_CLIPBOARD_BENCH_ROWS=1000000 cargo test --locked -p deskfuse-engine clipboard_library::performance_regressions::scale_benchmark -- --ignored --nocapture
```

探针包含 1000 个分组、分页、短中文搜索、FTS 搜索和稀疏分组。每项 20 次，记录 P50/P95；门槛 P95 < 300 ms。它验证元数据基数，不能作为 100 GB 原始正文冷盘读取、UI 首帧或实机跨设备验收证据。

实机验收目标：界面操作反馈 P95 ≤ 50 ms，本地文本粘贴热态 ≤ 150 ms/冷态 ≤ 300 ms，首屏热态 ≤ 100 ms/冷态 ≤ 300 ms。另需测试 2/20/100 GB 正文、快速连续回车/关闭重开、后台迁移同时增删改、断网重连、不同目标应用焦点恢复和双设备同步；需从触发到剪贴板准备和目标应用收到粘贴分别计时。
