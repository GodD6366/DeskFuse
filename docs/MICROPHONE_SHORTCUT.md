# 麦克风共享快捷键

麦克风共享开启后，可选择 Fn（Quartz key code 63，modifiers 0）、单个普通按键（如 F6）、单个左右修饰键（如右 Option），或组合键。Caps Lock 是切换键，不用作按住说话。快捷键必须与目标语音软件的设置一致。第三方软件是否接受模拟 Fn／组合键，由双机实测确认。

快捷键不启动或停止音频采集。语音软件读取虚拟麦克风后，由麦克风共享会话启动音频；按下／释放仅送到语音软件，保留松键后的尾音读取。

## 路由

- 配置通过 `ServiceControl::set_microphone_shortcut(enabled, key_code, modifiers)` 发送到现有签名输入进程。默认关闭，原有普通键鼠共享保持其既有行为。
- 控制端物理按下：选择该时刻键鼠控制所在的设备。
- 被控端物理按下：若本机持有当前接收控制租约，原样交给本机输入法；否则在已经授权的输入连接上请求主控，由主控选择当前控制设备。
- 每次按住使用独立的 `MicrophoneShortcutOpen` 流（协议 tag 36，能力 bit 18）；首次选定目标后不随鼠标跨屏改变。当前控制租约的离开不会提前结束该按住。
- 双端配置须一致。接收端核对已配对设备、设备网络成员、当前输入授权、来源主控、配置和原生权限；第三方设备不能借此注入任意键。
- 物理事件在普通共享队列前判定目标。目标是本机时，按下和释放直接透传原始事件，不替换成模拟按键；即使按住期间跨屏，释放仍透传本机。远端 Fn 按下／释放使用同一 HID 系统状态表，注入事件沿用专用标记并忽略回捕；Fn 边沿还核对实际变化的 key code，避免其他修饰键事件误触发。Fn 不跟随普通 modifiers 跨屏迁移。
- 远端按住每 200ms 续期，缺失 1.5 秒的按住状态即释放；断线、撤权、锁屏、功能关闭、紧急收回、录制快捷键与进程退出同样释放。
- 通道只传递按住状态与快捷键元数据，不传音频、转写或输入框内容。音频尚未开始时也可触发语音软件。

## 手动验收

两台 Mac 安装相同测试版并开启麦克风共享、键鼠共享和原生权限；在目标语音软件中设置一致的快捷键。

1. 鼠标位于 B 时，分别从 A、B 的物理键盘按住 Fn，确认 B 开始录音；释放确认结束。
2. 改为组合键重复，并确认普通组合键、紧急收回和设置中的快捷键录制仍工作。
3. 按住期间切换控制目标，确认此次释放仍送到原目标；下一次按下使用新目标。
4. 远端按住期间断开连接／关闭功能／锁屏／紧急收回，确认按键释放；恢复连接后不会重放旧按下。
5. 在没有任何应用读取虚拟麦克风时按下，确认快捷键仍能唤起语音软件，再按读取状态启动音频。

上述步骤是实机验收；协议与按住状态自动化回归不能证明第三方语音软件已接受模拟按键。

开启调试日志后，导出的诊断中 `microphone_shortcut_*` 记录配置、按下／释放、原始事件透传、接收路由、拒绝、连接和注入失败。只记录快捷键及设备元数据，不记录输入内容；`active` 仅表示通道／注入调用已执行，不代表输入法已接受。

录制监听 keyDown／keyUp／flagsChanged，按松开确认单键，识别左右修饰键；Fn 按系统实际上报的 key code 63 识别，不按键盘上左右位置区别。5 秒未收到事件时显示未检测提示，仍可继续尝试其它键；不会把未上报的 Fn 保存为一次成功录制。F1–F12 的系统 function 标记不视作额外的 Fn 组合要求。
