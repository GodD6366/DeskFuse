# DeskFuse 内置远程应用测试版

## 双机使用

两台 Apple Silicon Mac 安装同一个本地签名的 DeskFuse 测试包。主程序最低 macOS 14.0；远程应用入口仅在 macOS 14.2+ 出现。

1. 使用 DeskFuse 原有设备配对，确认设备在线。
2. 在被控 B 的设备页选本机，开启“允许已配对设备使用本机远程应用”。允许 DeskFuse 屏幕录制，并保持现有输入服务辅助功能授权。
3. 在 A 的设备页选择 B，点击“远程应用”弹出应用列表，运行中的应用置顶；单击应用即进入远程画面。
4. 首帧显示后自动申请控制；申请失败时保留画面，可点击重试。支持移动、左右/其他鼠标按钮、双击、拖动、滚轮、键盘和组合键。点击画面外或按 Control+Option+Escape 释放控制。
5. 默认使用捕获区域原生像素尺寸，提供分辨率比例/像素预算、刷新率和 1:1 查看选项。诊断栏显示实际配置及有效呈现帧率。

无需另开独立测试程序、填写 IP、交换口令或处理独立 TLS 证书。关闭远程窗口不会退出 B 的应用。最小化当前测试窗口会结束会话，需要从设备页重新打开。

## 本次集成边界

- 压缩 H.264 和会话命令复用现有认证 QUIC 连接上的专用双向流。原始像素缓冲保留在 Swift，使用 ScreenCaptureKit、VideoToolbox 和 Metal。
- 输入经有界 IPC 交给既有签名 `deskfuse-input-service`，通过独占握手暂停跨屏共享；控制绑定已授权设备、会话和画布版本。租约失效释放按键。
- 远端访问默认关闭；配对仍是授权前提，撤销信任会关闭连接。
- 当前是主程序集成测试版，不代表原始 P0–P3 计划全部完成。网络自动降档/恢复、完整自动桌面兜底、粘贴内容到达屏障、无缝重连及原计划独立输入网络仍需后续完成。
- 1080p60、原生高分辨率、90/120Hz、双机输入延迟及八小时稳定性需要实机验收；编译与协议测试不替代这些指标。

## 优先反馈

先测试点击、双击、右键、拖选、窗口拖动、滚动、Command 组合键、中文输入；再测试关闭/失焦/断网时是否释放按键，以及重新打开后能否控制。记录两端系统版本、源/编码尺寸、有效 FPS；故障时保留两端 DeskFuse 诊断。
