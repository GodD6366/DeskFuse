# 文件复制、按需传输与缓存

状态：2026-09-05 用户确认，2026-09-15 补充进度归一、目录内符号链接与大量小文件背压。本文件定义预期行为；运行证据另存于 `artifacts/validation/`。

## 使用路径

1. 本机复制文件/文件夹后，向可信已连接设备发布轻量文件引用。此时不读取完整文件、不打包、不发送文件正文。
2. 目标机器实际粘贴时，异步请求对应内容并显示准备、接收和校验进度。macOS Finder 的 Command-V 在按键时记录文件引用，建立显示“路径获取中”的任务，后台主动查询一次目标目录，拿到目录后绑定独立粘贴任务；传输完整性校验完成后，自动将缓存内容保存到该目录，不要求第二次粘贴。
3. Finder 路径查询成功后，粘贴任务绑定传输 ID、剪贴板版本和目录身份。此后等待期间切换目录、应用或复制新内容，不改变已建立任务的目录，也不取消该任务；旧任务不能覆盖新系统剪贴板。同一传输、同一目录的未完成请求合并，不同目录复用同一已校验缓存分别交付。完成前已经排队的重复按键不额外落盘。非 Finder 应用仍按原目标应用和剪贴板版本校验后回放一次；切换目标或新复制则只保留缓存，不向其他应用发粘贴。
4. macOS 全局进度浮窗不抢焦点，切换应用、关闭主窗口和全屏 Space 时仍可见。发送端显示实际发送字节，发完显示“等待接收端校验”，现有 ACK 只代表接收完整性校验，不等待本地目录交付。接收端粘贴任务分为路径获取、接收、校验、保存到绑定目录及完成，网络字节与本地保存字节分别记录；只有目标目录保存结束才显示粘贴完成。快照合并为最新值，通知可靠投递，终态不能被迟到进度覆盖。取消提示显示 3 秒后自动收起，也可手动提前关闭；完成任务立即收起，失败提示保留至手动关闭。收起只影响浮窗，传输页仍保留记录；活动任务的关闭操作仍是取消。
5. 抽屉菜单的显式“发送”仍立即开始传输。普通暂存和本地拖出不要求远端设备在线。

源引用在复制时只记录文件身份、大小、内容修改时间和目录结构；在原有有效期内不因新复制提前销毁，以便接住仍在网络途中的粘贴请求。开始传输后，源引用与取消状态绑定该任务，不再绑定系统剪贴板版本；Finder 标签、扩展属性或权限引起的 Unix `ctime` 变化不作为内容修改。按需扫描前后仍校验源引用，接收完成仍验证完整内容哈希。显式发送在扫描结束、首个 Offer 发出前绑定当前连接；响应粘贴请求始终绑定原连接。任务开始发送后，正文和取消帧都不能跨到重建的新连接。

## 目录与大量小文件

- 包含 `node_modules` 的目录按原目录结构传输；目录内部的相对符号链接作为链接保留，不跟随目标读取内容。顶层符号链接、绝对链接及指向所选目录之外的链接明确拒绝，并提示包含完整项目目录后重新复制；不能静默跳过文件。常规文件保留可执行权限位，不传递 setuid/setgid 等特殊权限。
- 元数据扫描不再受旧的 10 万项上限阻断；最多 100 万项、展开后清单最多 256 MiB，超限提示分批复制。超过 64 KiB 的清单压缩传输，仍受既有单帧大小限制，不放宽网络帧上限。复制/准备扫描可取消，按需哈希阶段显示已扫描项数；完整性校验仍在交付前完成。
- 文件清单先确认接收，正文每至多 16 帧等待接收队列的累计确认。队列满时保留一个有界待入队帧并暂停排空网络事件，继续处理取消、磁盘完成和定时事件；不能因为短暂队列满直接失败。队列确认只用于限流，不表示文件校验或 Finder 保存完成。大目录最终校验确认允许最多 10 分钟，断线与用户取消仍需结束对应任务。
- 读取块时对有序清单做二分查找，避免大量文件导致逐块线性查找。落盘不逐块强制刷新磁盘，完整文件校验后再刷新。
- 路径获取开始即关联粘贴任务与底层接收任务，进度页及浮窗只展示逻辑粘贴任务；路径查询阶段不被网络进度覆盖。迟到源进度只能传播已接受状态，不能覆盖终态。校验阶段明确显示“校验中/等待校验”，不以 100% 冒充完成；浮窗无活动/失败提示时关闭并释放原生窗口及旧内容。
- 本次文件清单与队列确认协议需要发送端和接收端同时更新；不兼容旧端时显示明确的确认超时，而不报告成功。

## Finder 目标与原子交付

- 按用户最新要求，每次 Finder Command-V 创建任务并显示“路径获取中”，后台主动执行一次 AppleScript，读取 `target of front Finder window as alias` 的 POSIX 路径与窗口 ID；以此次查询结果作为保存目标。不再轮询/缓存目标目录，不使用 300 ms 新鲜度门槛，也不因查询前的点击或导航标记拒绝任务。用户已明确不要求处理按键至路径返回之间切换目录的极短窗口。
- 查询阶段重复按键合并到正在获取路径的任务；取消立即结束该任务，迟到结果不能启动传输。路径取得后继续使用同一任务 ID 接收/保存，不要求再粘贴一次。路径获取开始、结束、耗时与取消写入元数据诊断。
- 固定脚本通过应用内 OSAKit 私有语言实例在后台执行、复用编译结果，事件 tap 不执行脚本/AX/磁盘查询。不从窗口标题、选中文件、侧栏或路径栏祖先猜目录，不依赖 AXDocument/AXURL 提供地址。
- macOS 通过“自动化 → uniDesk → Finder”授权查询，应用含 NSAppleEventsUsageDescription 与 Apple Events 签名 entitlement；拒绝授权、取消、Finder 忙碌/超时及不可转换的虚拟位置显示具体原因与错误码。不记录脚本返回的完整路径或原始错误正文。
- 辅助功能保留焦点、搜索与改名/对话框校验，不作为目录路径来源。获取路径时检查当前编辑/搜索上下文，不再执行前后两次目录查询；路径返回后固定目录身份。只在原生明确识别桌面焦点时请求 Finder 的 desktop alias，不能根据无窗口推定桌面。搜索结果、编辑状态及无法确认的位置继续拒绝。
- AX 查询对每个对象单独限制超时，对忙碌响应最多重试一次；可选标识/描述读取失败不否决已核验目录。AX 错误仍区分接口授权、忙碌及失效窗口，并保留属性名与错误码。
- 目录通过文件描述符及文件系统身份固定；移动、删除、替换、无权限或磁盘不足明确失败。每个顶层文件/文件夹先在该目录的本任务私有暂存区完整复制，再无覆盖原子提交。已有同名内容保留，新文件以 `name (1).ext` 递增编号；同名文件夹整体改名，不合并覆盖。
- 原始文件、已交付副本及其他任务暂存不参与取消清理。部分成功时记录已提交顶层项目，重试建立新尝试且只保存剩余项目；失败缓存及正在工作的缓存受租约保护。进程退出取消尚未结束的保存，本轮任务不作为重启后的自动重放队列。
- 只有可解析的真实目录自动交付；失败原因保留在传输记录和不激活浮窗。日志仅记录粘贴/传输 ID、阶段、字节及时间，不记录完整目标路径或文件内容。

## 连接中断

自动同步只发送当前连接建立后的新复制；重连不补发旧内容。尚未校验完成的文件接收与对应粘贴任务在断线时失败，需要重新复制或显式重新发送；已校验缓存开始的 Finder 本地目录交付不依赖源设备继续在线。文件引用安装确认、逐连接取消和大图片分块规则见 [剪贴板与连接恢复](CLIPBOARD_STABILITY.md)。

## 剪贴板历史持久化

- 本机 SQLite 数据库 `~/Library/Application Support/uniDesk/state.sqlite3` 保存按天保留的普通剪贴板历史（默认 30 天，不限条数），包含来源、完整文字、图片、原始多格式内容和文件引用；预览从原始内容生成。
- 新复制、去重置顶、历史淘汰和清空同步写入数据库，启动恢复最近摘要，完整查询在数据库分页；恢复列表本身不写系统剪贴板，也不重新向其他设备发送历史内容。
- 文件内容仍由现有源文件和传输缓存管理，不额外将文件正文塞入数据库；路径失效时沿用明确的不可用提示。普通历史与手动列表归档分离；缓存清理不删除手动成员，只使相关文件明确显示不可用。列表内文件再次使用时按稳定资源身份请求并校验，不能把旧连接的 Deferred TransferId 当成永久引用。
- 数据库写入或恢复失败显示错误，不记录剪贴板正文；数据库文件仅当前用户可读写。列表保留、来源元数据和跨设备同步见 [剪贴板列表契约](CLIPBOARD_LIBRARY.md)。

## 小文件提前传输

- 作为可关闭的独立配置；默认关闭，以粘贴时传输为默认体验。
- 阈值默认 10 MiB，可配置并持久保存。界面明确单位，按整批实际总字节数判断，文件夹递归计算，未知大小按需处理。
- 开启后，阈值内文件可提前接收；目标机器后续粘贴复用校验后的缓存。
- 配额不足或无法确认大小时保留按需引用，不为提前传输驱逐活跃数据。

## 最大占用与清理

- 缓存上限可配置并持久保存，初始建议 1 GiB。计入应用管理的临时/接收/完成文件；分块写入前检查配额，并发任务不能重复消费同一剩余额度。
- 对可回收的历史内容按时间回收。当前粘贴、接收、导出以及仍需使用的文件具有明确生命周期保护；活跃内容超过可用额度时暂停接收并提示容量不足。
- “清除历史传输文件”释放应用缓存，不只删除 UI 记录；显示当前占用、释放字节、保留活跃任务和失败情况。
- 只能删除应用私有缓存根目录内由应用管理的内容，拒绝符号链接逃逸。用户原始文件、导出文件和 Finder 粘贴后的副本不受清理影响。
- 清理旧缓存后，历史记录仍可表示该次传输，但不再承诺本地文件可用。再次使用需重新请求或明确告知来源已失效。

## 验收场景

- 大文件复制后、粘贴前：无文件正文传输且无大规模预读；目标粘贴才开始，显示实际进度并校验结果哈希。
- 开启/关闭提前传输、阈值上下边界、多文件和文件夹总量、重启后配置保留。
- 同一引用重复粘贴及多目录粘贴；等待期间切换 Finder 目录/应用、新复制；原目录内容哈希与目录结构、一次落盘、终态进度不滞后。
- 同名文件/文件夹保留两份、部分成功后只重试剩余项目、目标目录移动/删除/只读、磁盘不足、取消、断线与校验失败。
- 单任务/并发配额、接收中的历史清理、缓存目录符号链接、清理失败、原文件/目的地内容完整性。
- 原生 Command-V、菜单粘贴和右键粘贴分别记录实际支持范围，不能以单元测试模拟请求宣称全部原生粘贴入口已验收。
- 测试使用独立临时目录和生成样例；用户实际历史缓存不会在自动验收时被清空。

## 工作流共享

共享可手动选择工作流或按发送设备、目标和内容类型匹配自动规则，具体契约见 [工作流](WORKFLOWS.md)。工作流只在发送端处理私有副本，保持文件引用先行和按需读取：普通复制不因规则开启而提前处理文件正文。请求开始后固定定义，输出接入现有缓存租约、接收校验和重试，不重复运行外部步骤。转换失败回退原内容并明确提示；取消、源失效和旧剪贴板任务不回退发送。
