# 局域网扫码传输

2026-09-15：macOS 侧栏「局域网传输」提供同一物理局域网内的手机网页入口。

## 使用行为

- 首次默认关闭，开关、首选网络接口及最近端口存于应用数据目录的 `lan-web.json`。开启后切换页面不关闭服务；重启应用按已保存开关恢复。
- 只监听当前选定的 Wi-Fi／以太网 IPv4 地址，不监听通配地址、VPN、AWDL 或虚拟桥接。首选接口不可用时自动选择可用物理接口；端口占用则分配新端口，网络地址变化后更新二维码。
- 同一局域网设备扫码直接进入，无账号、口令或接收确认；这不会创建可信设备或授予键鼠控制权限。关闭服务会使网页不可用。
- 手机发送文字或多选照片，按队列接收并加入现有 SQLite 剪贴板列表。照片保留上传得到的原文件；浏览器自身选择或转码后的文件就是接收原件。
- 成功后自动写入 Mac 剪贴板；若接收期间剪贴板已经变化，只入库、不覆盖较新的内容。多图正常连续上传时，最后一张为当前剪贴板。是否继续同步给已配对设备遵循现有剪贴板同步开关。
- 网页复用完整列表、搜索、分组及来源筛选，支持分页、列表／瀑布流和文字／图片预览；不提供历史删除、标题编辑或分组管理。
- 文字复制尝试可用的浏览器复制能力，失败后选中文字并明确要求手动复制。局域网 HTTP 不保证自动复制 API 可用。
- 图片可预览、长按保存预览、下载原件。文件直接下载；目录或多文件导出为 ZIP。不自动请求远端未落盘内容，不下载符号链接或特殊文件。

## 网页交互（2026-09-15）

- 顶部为“传输 / 查看”两个 Tab，默认传输；切换不清空输入草稿、上传队列或筛选。Tab 支持左右方向键及 Home / End。
- 查看页文字和图片点击打开预览弹窗，不提供“展开全文”。弹窗从加载态起固定外框尺寸，文字内部滚动、图片等比适配，避免内容返回后撑大。卡片底部保留独立复制、保存与下载操作；复制不会触发预览，读取完整原文，HTTP 自动复制不可用时在卡片内选中文字提示手动复制。
- 瀑布流内边距设置在卡片本身，桌面16px、窄屏14px、超窄屏12px，文字和图片都留边。
- 图片卡片直接提供“保存相册”和“下载原文件”。保存相册打开图片页面，由用户长按选择系统保存操作；卡片和预览底部不常驻操作教学提示。保存图来自预览端点（最大2048px），原始格式通过下载原文件保留。

## 实现边界

- Rust 引擎内嵌 Axum HTTP 服务与静态资源，无云服务、CDN、Node 服务或额外部署。Swift 通过 FFI 的 `lan_web_state` / `configure_lan_web` 读取投影并修改设置；二维码由系统 CoreImage 生成。
- HTTP 仅开放状态、列表、条目读取、图片、下载、文字接收、单图 multipart 接收和任务状态。条目 ID 在 JSON 中为十进制字符串；不允许客户端传入任意本地路径或通用引擎命令。
- Host／Origin 和跨站请求来源受检查。网页内容只作为文本渲染，静态资源同源；接口及内容不使用持久 HTTP 缓存。
- 一次照片请求上限 256 MiB（另允许 multipart 开销），需提供请求 Content-Length；文字 JSON 请求上限 1 MiB。接收前预留共享缓存容量，预留包含 multipart 开销。串行提交，未完成请求取消时清除自有暂存，不删除已入库文件。
- ImageIO 生成有方向处理的预览；最大边 2048 px，预览输入限 128 MiB。预览失败或超限时保留原文件，明确提示；原件下载不缩放。
- 下载租约随响应数据流保留。ZIP 暂存在共享缓存配额内，响应结束或取消后释放；源文件、已下载的目的文件不受影响。
- 手机重试沿用 request_id。本次运行最近 100 个任务保留完成回执；同一已完成请求直接返回回执，不重复写剪贴板。任务记录不跨应用重启持久化。
- 网页只在可见时每 2 秒检查列表修订号，变化才刷新结果；Mac 任务页每秒读取服务投影。日志不记录正文、图片内容或完整源文件路径。

## 验证边界

构建、签名、DMG 完整性与 NAS 校验不等同于手机扫码、浏览器复制、照片保存、Finder 粘贴或真实局域网验收。实机需覆盖 iPhone／Android、中文长文本、多图、HEIC、文件夹下载、缓存不足、网络变化和上传期间另行复制。
