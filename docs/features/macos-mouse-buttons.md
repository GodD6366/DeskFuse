# macOS 鼠标自定义

设置 → 鼠标提供通用按键映射，默认关闭，修改后自动保存。普通鼠标支持系统报告的 0–31 号按钮、Command/Shift/Option/Control 修饰键组合、鼠标按钮替换、禁用和录制键盘快捷键。预设切换桌面、Mission Control 等动作读取本机已启用的系统快捷键；未覆盖时沿用 macOS 默认值，关闭或无有效键盘绑定时显示明确错误。

## MX Master 3 / 3S 原生 HID++

不依赖 Options+、SteerMouse 或 Solaar 进程。通过非独占 IOHIDManager / IOHIDDevice 访问 Logitech 的 vendor-defined interface，查询设备名称、`REPROG_CONTROLS_V4 (0x1B04)` 的动态 feature index 和实际可 diversion 的 CID。

- 普通五键仍走 CGEvent：左、右、滚轮按下、后退、前进。
- 拇指托上的手势键是 `0x00C3`；滚轮后方顶部小按钮是模式切换键 `0x00C4`，不是中键。
- 配置分别以语义 ID 195 / 196 持久化与同步，绝不将它们当作 Quartz 按钮或猜测的按钮 6 / 7 注入。
- 第一版两个扩展键支持默认快捷键、自定义快捷键和停用；暂不支持修饰键分层、鼠标点击/拖动映射或按住移动的方向手势。UI 和 Rust 校验均限制这个范围。
- 查询 `getCidInfo` 的 DIVERTABLE 能力（0x20），只接管实际存在、可 diversion、非 virtual 的两个目标键。
- `setCidReporting` 使用临时 diversion，设置值 0x03；恢复时使用带 valid bit 的 0x02。不改变 persistent diversion、raw XY 或固件 remap。
- 接管前检测已有 diversion，不覆盖其他程序已接管的按键；设置后回读确认，失败在 UI 显示并重试。
- 采集期间临时接管两个键，按下后保留接管到收到松开；关闭采集、关闭功能、移除绑定会恢复。设备移除会补齐已生成快捷键的松开，正常停止会尝试恢复已接管的键。进程强杀/设备突然断电不保证恢复请求能送达。
- 直接连接依次尝试 slot 0xff / 0x00，成功后不重复枚举别名；接收器枚举 slot 1–6。支持路径包含 Bluetooth、Unifying、Bolt，但仍需要逐路径实机验收。
- G502 HERO / G502 X 专用 HID++ 控件适配尚未实现；其已上报的普通系统按钮仍可绑定。

## 执行位置

普通按钮：主线程 session-tail tap 执行映射，晚于共享捕获的 HID/session-head tap。远程控制期间原始按钮走既有共享协议，由受控 Mac 执行动作。按下时固定动作直到释放，按钮替换保留点击次数并转换拖动事件。

生成的系统快捷键投递到 HID 层，发送完整修饰键按下/松开，方向键保留 Fn + NumericPad 固有标记，而非只经 session tap proxy 继续向应用传递。同时按住多个映射键时引用计数修饰键，避免提前松开。DFMB 标记与本进程来源过滤防止重新转发或再次触发应用自身快捷键。系统快捷键仍需在系统设置中启用，桌面切换要求对应方向存在桌面。

HID++ 扩展键：在鼠标连接的 Mac 解析 CID 并解析映射，输出带 DFHI 标记的物理来源键盘动作。共享捕获只对此标记豁免本进程合成事件过滤，远程期间通过已有键盘传输执行于受控 Mac，不发送原始 CID。因此两端配置短暂不一致时，扩展键以鼠标连接端配置为准，普通键以受控端配置为准。

## 配置同步

- 使用既有可信、已连接且网络允许的设备会话；不依赖剪贴板同步开关，也不写入系统剪贴板。
- 只有 macOS 宣告 `MAC_MOUSE_SETTINGS` 能力；未支持该能力的版本与 Windows 不接收广播。使用新增 CID 的配置要求参与的 Mac 均升级到支持 HID++ 配置的版本。
- 私有 MIME `application/x-deskfuse-macos-mouse-settings+json`，最大 16 KiB，最多 64 项映射。
- SQLite 独立设置键 `mouse_settings_v1` 持久化完整配置及逻辑版本。
- 完整配置按 `(counter, author)` 字典序决定胜者，不依赖电脑时钟。离线同时编辑不会逐按钮合并；恢复默认也是有版本的更新。
- 配置变动或每 5 秒交换一次完整状态，接收端仅接受更大版本；原生 UI 每秒刷新。未提供远端确认状态。
- 同步启用状态与映射，不同步权限、设备句柄、feature index、接收器 slot 或 diversion 所有权；每台 Mac 需自行授权。

## 采集并绑定

设置 → 鼠标 →「采集并绑定按键…」打开独立面板。点击开始后有 10 秒采集窗口，捕获下一次系统鼠标或 HID++ 扩展按键的按下并等待松开；确认松开后才允许「应用并启用」。首次发现设备可能需要数秒，超时可重新采集。

结果显示真实系统编号或 HID++ CID，选择预设后直接应用。普通键使用设置页当前修饰键组合；MX 扩展键始终应用到默认映射。自定义快捷键在主列表录制。Esc 或关闭面板退出采集。界面同时显示 HID++ 发现、权限、占用或通信超时状态。

## 验收边界

自动化覆盖协议能力标志、临时接管/恢复编码、报告 framing、按下/松开快照、配置 JSON、CID 校验与同步、合成事件路由过滤。原生构建不代表设备兼容验收。

实机需验证：MX Master 3 与 3S 分别在蓝牙/接收器连接下的七键、捕获后应用、取消与关闭后恢复模式切换、休眠唤醒/拔插、系统桌面切换、两台 Mac 在线/断线同步与跨屏执行位置。当前实现不宣称这些硬件验收已经通过。

## 采集与性能诊断

- HID++ 只打开报告描述符同时包含 `0x11` 长报告输入/输出的接口，不把普通鼠标的 `0xffbc` collection 当作 HID++。
- 功能关闭且不在采集时停止 HID 管理器。配置变更立即协调；后台发现/恢复检查每 30 秒执行一次，不再每 2 秒重复查询和写入。
- 匹配的 HID++ 1.0 / 2.0 错误响应立即结束请求，区分协议错误、写入失败与通信超时。
- 用户点击采集时可请求输入监控授权；面板提供系统设置入口。导出的诊断包含授权状态、接口清单、设备/slot/feature/CID、接管状态、请求与错误计数及最近 24 条通信摘要，不记录按键文本。
- 诊断中的普通按钮计数区分滚轮按下与 HID++ 模式键。真实按下/松开是否抵达仍需在对应连接方式下验收。
- 剪贴板分页不等待总数统计；默认列表复用已有计数，筛选总数延迟 400 ms，独立统计请求通过 SQLite progress handler 限制为 750 ms，超时不影响分页。

## G502 LIGHTSPEED 实体键（附加快捷键）

通过动态发现 `MOUSE_BUTTON_SPY (0x8110)` 读取实体按键快照，不依赖 MX 的 `REPROG_CONTROLS_V4`。保留鼠标原有 DPI、配置切换和 G HUB 行为，只附加 DeskFuse 快捷键；不写入板载配置，也不提供禁用原功能或鼠标按钮替换。

- 采集面板选择「G502 实体键」，再开始采集。系统按钮/MX 模式与原始实体键模式分开，避免同一次点击抢先被系统按钮捕获。
- 使用独立语义 ID 208–223，显示为实体键 1–16；实际可用数量由设备查询决定。本机 G502 LIGHTSPEED 返回 11 键，不猜测每个编号对应的物理位置。不要同时绑定同一键的系统按钮和实体键输出。
- 两字节位图按高字节在前解析，支持同时按下及松开快照。配置删除期间保留已按下键的松开监听；停止时补齐快捷键释放并发送 stopSpy。每 30 秒重新协调监听，处理鼠标休眠后状态丢失。
- 原始键只支持无修饰键分层的快捷键绑定。G502 HERO / G502 X 尚未通过型号门控，不宣称兼容。
- 本机接收器 `046d:c539`、slot 1 实测发现 feature index `0x0a`，startSpy / stopSpy 均应答成功并收到实体键报告。这不代表所有实体键、桌面切换或跨设备执行已验收。

协议调查参考：https://github.com/pwr-Solaar/Solaar/issues/3316 、https://gist.github.com/myaiexp/ce62498e0d702f2a3b289be58218822c 。功能与键数同时以实际设备查询为准。

2026-10-17 本机二次监听：120 秒内收到 80 条 Spy 报告，出现实体键 1、2、3、4、5、7、8、9 的非零位图以及归零释放报告；未将用户操作顺序猜测为物理位置标签。实体键 6、10、11 和绑定后的桌面切换仍待实机验证。开发版已完成构建及严格签名验证；相关 Swift 15 项与 Rust 配置 5 项测试通过。

### 鼠标设置界面整理（2026-10-17）

- 按键分配分为「通用按键」「G502 LIGHTSPEED」「MX 扩展键」，避免跨型号混排。切换类型清除修饰键编辑层，原生键始终使用默认层。
- 「识别按键」从当前 G502 分类进入时默认选择 G502 来源；未发现按键时展示识别引导，不伪造设备在线状态。
- 采集面板分为识别、选择动作两步，监听时显示剩余秒数；收到松开后才能保存并启用。设备状态、权限入口和协议限制折叠展示。
- 开关、按键映射、组合键与同步保持原有持久化语义；仅保存新的按键动作时启用功能。

## G502 实物图编辑器

G502 LIGHTSPEED 使用随应用打包的官方顶视、侧视照片；点击图上的位置，仅编辑当前按键。滚轮按下、左拨、右拨在同一编辑区切换，机械解锁键不映射。图片来源见 `resources/mice/SOURCES.md`。

物理位置与 Button Spy 原始位序不直接等同。首次点击「识别这个位置」后，在 10 秒内按下并松开对应实体键，收到事件后需点击「确认这个位置」才保存位置关联；超时、取消、切换位置不会写入关联。关联保存在本机 UserDefaults `mouse.g502.physicalLocations.v1`，不改写已有快捷键，也不随快捷键配置跨设备同步。重新确认仅移动位置关联，原有动作仍按原始事件 ID 保存。

### 显式保存（2026-10-18）

G502 动作选择与快捷键录制先作为当前按键草稿，点击「保存并应用」才提交；切换按键或类型会丢弃未保存草稿。保存状态仅在持久化返回后显示成功。保存已确认的左/右/中/前进/后退位置时，会清除对应通用按钮的 DeskFuse 映射（含修饰键层），防止通用事件与 HID++ 实体事件分别执行动作；不会改写鼠标固件原生功能。此配置仍按原有规则同步到其他 Mac。

执行提示区区分等待实体按键、收到原始事件、发送快捷键与系统快捷键解析失败。“已发送”只表示投递键盘事件，不等于系统已完成桌面切换。

### 按键就地编辑

点击实物图上的按键热点，在该热点旁打开原生浮层，直接选择动作并保存；不再使用固定右侧编辑栏。滚轮的按下/左拨/右拨在同一浮层切换。未确认位置时，浮层沿用原有实体按键确认流程。关闭浮层或切换视图会停止监听和录制，并放弃尚未保存的动作草稿，不修改已保存配置。

### 自动保存（后续交互调整）

G502 功能选择和快捷键录制完成后立即提交并应用，取消独立保存按钮和动作草稿。保留持久化成功/失败状态及通用映射去重；位置识别仍需单独确认，避免误关联。此规则替代此前显式保存及关闭浮层丢弃动作草稿的说明。

### MX Master 3 实物图与视角切换

MX Master 3 页面提供顶视、侧视照片及按键旁自动保存浮层。左/右/中键与前进/后退使用通用 Quartz 事件，手势键 CID 195 和滚轮模式键 CID 196 仅在 HID++ 实际枚举支持后可编辑。横向滚轮和底部 Easy-Switch 不提供映射；扩展键配置会临时接管原行为，清除动作时恢复。照片为 MX Master 3 for Mac 的深空灰外观。

视角切换使用独立按钮；图片、背景和描边不参与 hit testing，画布限定命中区域，避免透明图片或装饰层遮住操作控件。配置仍沿用已有共享模型，不代表已实现按设备配置隔离或自动设备切换。
