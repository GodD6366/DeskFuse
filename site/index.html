安装

两种方式，一分钟上手

Homebrew 推荐

macOS 14+ · Apple Silicon，一条命令装好，随 brew 更新。

brew trust --cask godd6366/unidesk/unidesk
brew tap godd6366/unidesk \
  https://github.com/GodD6366/unidesk-release
brew install --cask godd6366/unidesk/unidesk

升级：brew update && brew upgrade --cask unidesk

手动安装 DMG

从 GitHub Releases 下载并校验，拖入 Applications 即可。

  1. 下载对应平台安装包与 SHA256SUMS
  2. 运行 shasum -a 256 -c SHA256SUMS 校验完整性
  3. 打开 DMG，把 uniDesk.app 拖进「应用程序」
  4. 按提示允许局域网访问；键鼠共享另需辅助功能授权

公开预发行经 Developer ID 签名并公证，可直接打开。
