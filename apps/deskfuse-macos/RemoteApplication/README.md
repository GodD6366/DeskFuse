# 远程应用双机交互测试包 0.0.2

适用于两台 Apple Silicon Mac，macOS 14.2+。这是独立的 P0 工程，不替换 DeskFuse 主程序。

## 双机使用

1. 两台机器解压同一个 `DeskFuseRemoteSpike-0.0.2-arm64.zip`，打开 `DeskFuseRemoteSpike.app`。
2. B 端退出 DeskFuse 主程序，在测试程序选择 **B 端 · 共享应用**。授予屏幕录制和辅助功能权限，点击“开始共享”。如果系统要求重新打开程序，按提示操作。
3. 将 B 端显示的局域网地址和完整连接密钥复制到 A 端。每次重新开始共享会生成新密钥。
4. A 端选择 **A 端 · 控制远端**，输入地址及密钥，点击“连接 B 端”。允许系统弹出的本地网络访问请求；B 端防火墙需要允许此应用接收入站连接（UDP 42427）。
5. A 端从远端列表选择应用，点击“启动 / 切换应用”，看到画面后点击画面获取控制。B 端保持目标应用在前台且不锁屏。
6. 测试左/右键、双击、拖动、滚轮、文字、组合键。输入法使用 B 端当前选择的输入法。
7. `Control-Option-Escape`、点击画面外或 A 端失焦会释放控制。普通 Escape 转发给 B 端。B 端切换到其他应用也会释放控制。
8. 分辨率默认保留 B 原生像素，刷新率默认跟随 B、最高 120 Hz。切档后等待新画面，再点击获取控制。1:1 查看时 `Option + 滚轮` 平移，普通滚轮发送给 B。

退出 / 断开不会关闭 B 上的目标应用。B 端最小化测试窗口会停止共享；需要让目标应用保持前台时直接切换窗口，不要最小化测试程序。

## 本版已接入

- B 端应用枚举、启动；A 端显示与鼠标、键盘转发。
- ScreenCaptureKit → H.264 硬件编码 → QUIC → 硬件解码 → Metal。
- 应用区域坐标映射、Retina、画面黑边排除、拖拽裁剪冻结。
- 独立签名输入子进程；一秒心跳租约、失焦释放、画面换代确认、旧输入拒绝。
- 临时 TLS 证书固定指纹及随机控制令牌；不接受其他证书或错误令牌。
- 同一个稳定的本地 Apple Development 代码签名身份及 Bundle ID，重打包不切换为 ad-hoc 签名。

## 测试边界

此包完成编译、协议往返、错误凭据拒绝、坐标与租约自动检查；未执行本机 GUI 输入测试，双机实际点击、输入法、拖动和性能需人工验证。

仍是独立实验链路：未接入生产 Rust 主连接或生产输入控制租约，测试 B 端需退出主程序。视频与控制使用一个独立双向 QUIC 流，尚未完成生产媒体分流。当前没有剪贴板跨机同步、自动桌面兜底、自动重连或实时自动降档；手动画质设置可用。系统保留的本机快捷键（如 Command-Tab）可能被 A 的 macOS 截获。桌面开关只改变 B 的采集画面，输入仍限于选择的前台应用，不是通用远程桌面。

macOS 14 使用一次性临时钥匙串承载会话 TLS 身份；macOS 15+ 使用纯内存导入。正常停止监听即清理，不改动登录钥匙串或系统信任设置。分发包为本地开发签名，未公证。

没有把构建成功或协议测试算作双机 1080p60、延迟、长稳验收通过。
