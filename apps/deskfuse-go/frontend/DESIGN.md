# DeskFuse MyGo UI · 设计规范

适用范围：`apps/deskfuse-go/frontend`。记录 2026-10-31 完成的「麦克风共享」页重设计（声桥），
以及同日确定的浅色应用 shell 排版、动效与交互基线。其他功能页沿用 shell 的浅色规范，
不复制本页的链路舞台。

## 1. 方向与功能契约

- 选定方向：声桥（Signal Bridge）。麦克风页回到与其他页面相同的浅色 shell，用一条
  从来源到去向的实时波形链路承载页面；提供方和使用方共用同一套版面，但两端的角色标签、
  设备身份、插口形态和状态文案随身份互换。
- 设计读取：功能型音频路由页，面向在两台 Mac 之间共享麦克风的人；用「安静的音频控制台」
  语言，倾向壳内浅色层级、发丝线和单一蓝色强调。
- 页面存在的理由：让用户一眼确认这台 Mac 站在声音链路哪一端、声音从哪台设备到哪台设备、
  是否正在传输、当前电平，并能完成身份选择、设备选择、权限处理、驱动安装和语音测试。
- 3 秒内必须获得：本机是提供方还是使用方、链路两端设备、是否正在传输、输入电平。
- 必须能完成的动作：切换身份、开关共享/接收、更换输入或来源、授权麦克风、安装/更新/
  重启/卸载虚拟麦克风、设为系统默认输入、语音测试、反馈问题。
- 已否决的方向：整页深色的「跳线台」；只靠右上角开关或颜色区分两端；用合成正弦波冒充
  输入波形；把身份选择压缩成一个分段 tab。

## 2. 主题与色板

麦克风页不再声明独立主题，只使用全局 token；浅色壳内不再出现 `chrome-dark`。

| 角色 | 值（浅色） | 用途 |
| --- | --- | --- |
| `--canvas` | `#f4f4f6` | 应用底色、舞台渐变落点 |
| `--surface` | `#fff` | 舞台内的设备卡、设置卡、弹层 |
| `--control` | `rgba(0,0,0,.04)` | 图标底、未点亮电平段、行 hover |
| `--line` | `rgba(0,0,0,.09)` | 卡片边框、行分隔、舞台网格 |
| `--text` | `#222` | 标题、设备名、主要数值 |
| `--secondary` | `#595959` | 说明、状态、单位、脚注 |
| `--accent` | `#3276f3` | 传输中、已激活、主开关、链路波形 |
| `--success` | `#28a745` | 已允许、在线、就绪 |
| `--warning` | `#ed8b23` | 需要处理但不阻断的状态 |
| `--danger` | `#e53935` | 错误、卸载等不可逆操作 |

规则：
- 蓝色只表示「有信号 / 已激活 / 可操作」，不铺大面积背景，不做渐变文字和彩色阴影。
- 两端的差异不靠颜色：用「本机/对方」角色徽标、来源与去向位置、实心设备图标与同心圆插口、
  以及「采集中/接收中」「使用中」等状态词区分。
- 系统深色模式下沿用全局 `@media (prefers-color-scheme: dark)` token；页面不自带第二套暗色。

## 3. 排版

- 标签与数值：`--font-mono`（`ui-monospace, SFMono-Regular, SF Mono, Menlo, Consolas`），
  用于 `PROVIDER / OUT`、`48 kHz`、`−14 dBFS`、`256 采样`、`DESK FUSE / MICROPHONE`。
- 正文与标题：系统中文字体栈（`-apple-system`、`PingFang SC`），不使用 WebFont 与斜体。
- 尺度：页面标题 21px/600；身份选择标题 27px（窄屏 22/20）；设备名 13px/600；
  设置行标题 11.5px/500；说明 10–11px；等宽标签 9–10px、大写、`letter-spacing: .1em`。
- 电平读数使用等宽字体和 `tabular-nums`；无信号显示 `−∞`，负值统一使用 U+2212。
- 中文段落 `text-wrap: pretty`，标题 `text-wrap: balance`；`span.no-break` 只保护
  「声音链路」这类不能被拆开的短语。

## 4. 布局

- 页面宽度上限 1120px，左右 24px 内边距；主滚动区是 `.mic-scroll`（`overscroll-behavior: contain`）。
- 页头：左侧标题 + 一句话现状（谁正在把麦克风传给谁）；右侧「切换身份」与主开关。
  主开关是可操作的 `role="switch"`，文案随身份变成「共享已开启 / 接收已开启 / 已暂停」。
- 舞台（唯一主视觉）：
  - 顶部一行：身份 kicker、带呼吸点的状态、右侧 `采样率 · 窗口 · 本机/远端输入`。
  - 中部三列：来源设备卡（206px）→ 波形链路（自适应）→ 去向设备卡（206px）。
  - 波形链路列分两行：居中的电平读数（`−∞ dBFS` + 12 段电平）和真实波形画布。
    电平描述的是「正在通过这条链路的声音」，所以放进链路而不是来源设备卡；
    设备卡因此只剩身份信息，两侧结构对齐。电平行占顶部 22px，底部留等高空白，
    画布中线仍与两侧设备卡的中线重合，波形不会从设备卡中心偏出去。
  - 两端设备卡结构一致：角色、状态、真实产品图与设备名、一行等宽底部事实。
    使用方去向仍是同心圆插口 + `DeskFuse Mic`。
  - 两端设备卡都用系统真实产品图（`devices.icon` 把 CoreTypes 图与原生同一解析结果栅格化，
    本机带 `hw.model`，对端按名称里的型号词回退），右下角小徽标标明该端贡献的是实体麦克风
    还是虚拟麦克风；使用方去向的徽标保留同心圆插口。
  - 底部事实行只写真实投影：提供方本机写麦克风授权状态，对端写线路类型与探测 RTT
    （没有线路数据时回退到设备连接说明），使用方本机一侧写读取应用或在线数量；
    默认输入与采样率在设置区的「来源 / 输入」「系统输入」行里，不在这里重复。
  - 窄屏（`760px` 以下）链路改为纵向：电平行仍在画布上方，高度从 272px 收到 196px。
  - 舞台背景只有 2%–6% 的蓝色径向渐变、底部 canvas 渐变和 56px 竖向网格；不用卡片投影。
- 设置区双栏（约 1.08 : 0.92）：左栏来源/输入、权限、可信设备、虚拟麦克风、系统输入、
  驱动维护；右栏语音测试、识别文本、隐私说明。
- 身份选择页：kicker + 「这台 Mac 站在声音链路的哪一端？」+ 两张并列方向卡；
  宽屏双列，窄屏单列；每张卡内部用「来源 → 箭头 → 去向」的小型链路图说明方向，
  当前身份显示「当前身份」徽标，已配置时右上角提供「返回链路」。
- 断点：
  - `1040px`：舞台设备卡收窄到 184px。
  - `980px`：身份卡改单列。
  - `760px`：页头改为纵向；舞台改「来源 → 纵向链路 → 去向」；链画画布切换为纵向
    （由同一 `matchMedia('(max-width: 760px)')` 驱动，避免桌面窄窗口误用纵向波形）。
  - `420px`：身份卡内链路的设备名与图标进一步收紧。
- 桌面应用最小窗口 960px 时舞台仍为横向三列，链画布保持横向；纵向只用于窄屏/LAN 预览。

## 5. 组件与状态

- 身份卡 `.role-choice`：整卡是按钮；hover 只抬起 1px 并加深边框；当前身份卡使用 40% 蓝边
  与极浅渐变；`busy` 时禁用，防止并发切换。选择成功后才关闭选择页，失败错误留在页内。
- 舞台提示 `.stage-notice`：只在需要处理时出现，一行标题 + 一行说明 + 一个动作
  （授权 / 前往设备 / 选择来源 / 安装驱动 / 重试）；与状态行不重复。
- 来源/去向设备卡 `.pod`：`is-live / is-warn / is-idle` 三种状态；
  状态点、边框和底色一起变化，但不整块降透明度。
- 设置行 `.setting`：图标 + 标题/说明 + 右侧动作或状态值；动作使用蓝色文字，
  完成态使用绿色对勾 + 文字，不使用第二个按钮。
- 语音测试：整块可点击的开始/停止按钮 + 12 段输入电平 + 可编辑识别文本；
  不可用时用 `Notice` 说明下一步并给系统设置入口。
- 驱动维护：折叠在 `<details>` 中，重启、重装、卸载各自有后果说明；卸载走确认弹层。
- 弹层 `.sheet`：`Teleport` 到 body，`role="dialog"` + `aria-modal` + 焦点落点 + Tab 循环 +
  Esc 关闭 + 关闭后焦点返还；容器本身不画焦点环，内部控件保留全局 `:focus-visible`。
- 覆盖状态：加载（BOOT）、服务错误（ERROR，含重试与反馈）、未配置、未配对、权限未授权、
  驱动未安装/旧版/未响应、来源离线、语音测试不可用、暂停。
- 空状态只描述下一步，不展示假数据；所有设备名、应用名、采样率来自真实投影。

## 6. 真实波形与传输

- 本地采集：`MicrophoneAudio.swift` 的 `AVAudioEngine` tap 在每次回调把单声道 48 kHz
  float 样本写入 `MicrophoneWaveform`（256 点，50ms 节流）；`current()` 在 0.9s 无更新后
  返回 `active: false`，页面回到待机线。
- 桥接：`MyGoBridgeServer.microphoneProjection` 在实时投影里返回
  `waveform / waveform_rate / waveform_active`；页面以 200ms 轮询，快照仍按 1.5s 刷新。
- 远端波形：沿用现有麦克风电平包（kind 4）。发送端在会话开始后的 6s 窗口内每 0.5s
  把电平写成 `-1.0` 哨兵；新版接收端看到后发 kind 6 请求（带占位字节，传输层拒绝不足
  2 字节的包；按秒重试），之后 kind 4 追加「点数 + float 样本」。窗口结束仍未收到请求
  即停发哨兵，此时对端是旧版本，旧接收端只在开头看到几个 0 电平包。哨兵不能只在静音时
  发：用户一开口电平就非零，握手永远完不成，接收端只能画直线。旧发送端不会发出哨兵，
  新版接收端也不会向它发请求。`deskfuse-transport` 允许 kind 1–6，单包仍受 4097 字节
  上限约束。
- 画布 `MicLinkCanvas.vue`：只绘制真实样本，不做合成载波；显示前对样本做 3 点平滑，
  峰值仍按原始样本计算。传输中只有一条连续的线，从来源插口走到去向插口——
  没有面积填充、没有大范围光晕、没有中心基准线，视觉重量低于两侧设备卡；
  前行的数据包和端口脉冲仍然保留，因为它们是「正在传输」的方向证据。
  幅度按峰值归一化到链路高度的 15%（峰到峰约三成；上限 40×，噪声地板 0.004），
  并取最近上升过零点对齐窗口，减少刷新时的横向跳动；语音常在 −40 dBFS，
  过低的增益上限会把整段说话压成直线。暂停/无样本时显示虚线待机；
  `prefers-reduced-motion` 下只画静态帧。
- 波形是页面的核心，不是装饰：没有真实样本时不伪造振幅，也不把电平值画成正弦波。

## 7. 动效与无障碍

- 全局动效 token：`--ease-out: cubic-bezier(.23,1,.32,1)`，`--dur-fast/base/slow`
  为 120/180/240ms；只过渡颜色、边框、阴影、位移，不写 `transition: all`。
- 传输态：状态点 2s 呼吸；链路上的数据包持续从来源移向去向；语音测试按钮在聆听时脉冲。
  非传输态全部静止。
- 入场：弹层 180ms 淡入 + 6px 上移 + 0.99 缩放；不使用 `scale(0)`，不使用 UI `ease-in`。
- `prefers-reduced-motion: reduce` 下关闭动画与过渡；动效不是状态信息的唯一载体。
- 焦点：全局 2px 蓝环 + 2px offset；弹层容器不画环；Esc、Tab 循环与焦点返还可用。
- 语义：舞台状态 `aria-live="polite"`；开关使用 `aria-checked`；身份卡使用 `aria-current`；
  装饰性 SVG 一律 `aria-hidden`；电平有文本 dBFS 读数，不只靠颜色。

## 8. 应用 shell 与共用控件

- `style.css` 维护全局 token、字体平滑、滚动条、焦点环与高对比度回退；其他页面不复制色值。
- 页面切换由 `.page-frame` + `Transition name="page"` 承担：离场 90ms 淡出，入场 180ms
  淡入并上移 5px。
- 导航选中态左侧 3px 强调条；hover/active 只改变背景与轻微缩放；健康状态数字用 `tabular-nums`。
- 麦克风页不再切换 shell 主题；`App.vue` 的 `chrome-dark` 绑定与规则已移除。

## 9. Do / Don't

Do：
- 先保证方向、两端、状态和电平可读，再考虑装饰。
- 用来源→去向的空间顺序、本机/对方标签和插口形态表达身份差异。
- 用发丝线、留白、等宽标签和单一蓝色建立层级。
- 错误信息说明下一步；危险操作写明后果并二次确认。
- 新增状态时同时给出加载、空、错误和恢复路径。

Don't：
- 不把本页改回深色或独立视觉世界；它必须与浅色 shell 连成一套。
- 不用颜色、开关或 tab 单独承担身份差异。
- 不绘制合成波形，不把动画当作真实传输的证据。
- 不新增卡片海、渐变光晕、彩色阴影、装饰性编号眉批或重复数值。
- 不在没有 `prefers-reduced-motion` 兜底时运行动效。
- 不为 hover-only 设备写交互；窄屏仍要能完成全部动作。

## 10. 实现边界

- 链路画布与同一列上方的电平读数是同一份真实样本；远端波形需要两端都运行本版本。
- 旧版本对端仍可正常传输音频，只显示电平与待机线，不显示远端波形。
- 波形缓冲与桥接投影不改变引擎 FFI；音频编码、传输与驱动路径保持原样。

## 11. 鼠标按键页 · 就地标注（2026-11-01）

选定方向：**B · 就地标注（Callout Sheet）**。侧栏入口与顶栏标题为「鼠标按键」，沿用浅色应用 shell，
把「看着鼠标找按键」与「一眼扫清当前全部动作」合进同一张硬件引线图纸画布，取消原先常驻占宽 340px
的右侧目录栏与遮挡机身的浮动 `.inspector` 弹层。

### 功能契约与供体 DNA

- **页面存在的理由**：让用户顺着机身按键引出的折线一眼看清每个实体键当前绑定的动作，就地点按即可换动作、
  录快捷键、切换滚轮模式或重新识别物理键位，彻底省去列表与实物之间的视线来回。
- **3 秒内必得信息**：当前设备与连接/电量状态、当前视角各按键的默认/已改动作、另一视角已修改按键数。
- **供体 DNA**：
  - `vercel`：使用 `0 0 0 1px var(--line), 0 2px 5px rgba(0,0,0,.035)` 轻边框阴影承载就地标注卡，
    字重严格限制在 `400 / 500 / 600`，序号（`01`–`09`）与键位代号使用等宽字体 + `tabular-nums`。
  - `apple`：实物居中净空构图，`< 5%` 透明度的 `16px` 微点阵图纸底，彩色仅用于已自定义动作与激活态的
    单一信号蓝 `--accent`，视角切换器采用 `999px` 胶囊并内嵌已改计数。

### 一个编辑器原则（统一就地标注画布）

实物位置图覆盖全部鼠标类型，共用同一套「顶栏设备与视角 → 中央机身与双侧引线标注卡 → 底栏修饰键层与状态」结构：

| 鼠标类型 | 中央载体 | 组件 |
| --- | --- | --- |
| G502、MX Master 3 / 4（有实拍图） | 真实产品图（`img.photo`）+ 锚点（`.hotspot`） | `MousePhotoEditor.vue` |
| MX Anywhere 3 / MX Ergo / MX Vertical（已适配、无实拍图） | 五键标准线稿示意图 + 底部扩展键胶囊 | `MouseGenericEditor.vue` |
| 被识别但不在支持列表 | 五键标准线稿示意图，标注真实设备名与「未适配」 | `MouseGenericEditor.vue` |
| 没接鼠标 | 五键标准线稿示意图，离线预配置 | `MouseGenericEditor.vue` |

- **左右分列与折线引线**：按按键物理横坐标自然分入左右标注列（如左键、侧键、DPI 键居左，右键、中键、模式键居右）；
  `ResizeObserver` 实时绘制从标注卡内沿到机身 `.hotspot` 圆心的正交折线（水平出线 → 斜向入点）。
- **签名交互**：悬停或键盘聚焦任意就地标注卡（或对应 `.hotspot`）时，该条引线与机身锚点同步高亮加粗；
  点击标注卡直接打开动作菜单，点击卡内「录制」原地进入 `请按快捷键…` 监听态（不降透明度，`Esc` 取消）。
- **跨视角可见性**：`顶视` / `侧视` 胶囊按钮直接显示该视角已自定义按键数（如 `侧视 · 3`、`顶视 · 1`），
  避免切到另一面时遗忘侧键映射。
- **特殊硬件状态就地承载**：
  - **滚轮模式**：当前设备支持 SmartShift / 棘轮切换时，直接在画布顶栏展示 `自由滚动 / 棘轮` 分段开关。
  - **G502 滚轮三向与物理重认**：滚轮标注卡内嵌 `按下 / 左拨 / 右拨` 切换；每张 G502 标注卡提供「重认键位」，
    点击后在该卡原地完成按下监听与确认，不弹遮挡浮层。
  - **MX 扩展键检测**：尚未检测到 HID++ 扩展键（`195` / `196`）时，对应标注卡原地显示「检测扩展键」入口。
  - **修饰键组合层**：支持组合层的模式在画布底栏提供 `默认 / ⌘ / ⇧ / ⌥ / ⌃` 键帽切换，标注卡即时反映当前层映射。
